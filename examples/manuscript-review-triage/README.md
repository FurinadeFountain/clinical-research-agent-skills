# 直观样本：文稿起草、独立审阅三级分流与静态门禁闭环

本目录用一组完全脱敏合成的器官微循环损伤实验文稿（小鼠急性肾缺血再灌注微血管内皮大分子渗漏实验），直观展示这套工作流在实际写作与改稿中如何配合：**客观格式与编号错误由本地脚本直接拦截，实质科学越界与方法细节落位由“独立审读 + 三级分流 + 唯一主笔改稿”闭环完成。**

## 四份对照材料（建议按顺序阅读）

1. **[研究记录（事实基准）](study-record.md)**：给定实验体裁（原始研究论文片段）、三组小鼠样本量（每组 $n = 6$ 只独立动物，含等体积 1% DMSO 溶媒对照）、再灌注 6 小时终点实测值（肾皮质/血浆 70 kDa FITC-dextran 荧光比值与动物均值层级的肾小管周毛细血管 ZO-1 连续性评分）、激光多普勒探头定标记录及三篇拟引文献的实际研究范围。
2. **[待修初稿（常见偏移样本）](draft-before.md)**：展示未经约束时极易同时出现的两类问题——
   - **科学判断偏移**：以 `"改善肾小管上皮修复反应（repair response）"` 等笼统词拔高再灌注 6 小时急性血管渗漏终点；漏写 DMSO 溶媒对照组并将每组 30 个免疫荧光视野误报为独立样本量；把临床观察性队列相关性改写为直接降低术后急性肾损伤发生率的因果证据；把光纤探头零点校准与麻醉细节塞进摘要首句形成超长防御长句。
   - **机械格式违规**：标题使用中圆点串词（`结果·讨论与临床转化`）、残留内部草稿路由标记（`路线 B`）、正文数字引文首次出现跳号（`[1]` 后先引 `[3]` 再引 `[2]`）。
3. **[独立审阅回报与三级分流台账](review-and-triage.md)**：展示无历史上下文的只读审阅子代理如何对照原始记录定位实质硬伤（`FAIL 1–3`）与落位失当（`WARN 1–2`），以及唯一主笔如何按**三级分流漏斗**处理意见（实质硬伤改入正文主干、标定与统计质控下沉方法专节、超出 6 小时急性验证定位的远期实验要求记录为“凭据不改”，1 轮收束）。
4. **[主笔修订定稿](draft-after.md)**：经唯一主笔重排后的成稿，实测终点、溶媒对照、动物样本分母与观察性引文边界全部对齐，且通过静态门禁复检。

## 本地一键复现脚本拦截与定稿放行

在仓库根目录无需联网或配置任何第三方包，直接运行文稿静态门禁即可对比修订前后的检查结果：

```sh
# 1. 检查待修初稿（返回退出码 1，精准报出残留标签、引文跳号、标题中圆点与摘要超长句）
python3 skills/scientific-drafting/scripts/lint_manuscript.py examples/manuscript-review-triage/draft-before.md

# 2. 检查主笔修订定稿（返回退出码 0，0 errors, 0 warnings）
python3 skills/scientific-drafting/scripts/lint_manuscript.py examples/manuscript-review-triage/draft-after.md
```
