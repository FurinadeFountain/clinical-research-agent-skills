# 练习：独立单位变了，结论会怎样？

**输入仅有三份：**[研究记录](design.md)、[视野数据](fields.csv)、[待修稿](draft.md)。数据和文字完全合成。每行记录一次视野读数；研究记录规定组别、目标量和推断边界。案例不需要账户、联网、下载数据或配置模型。

在一个新会话里只提供这三份输入、仓库的共用规则和所需技能，请 Agent：

> 根据研究记录和原始表修订摘要、结果、表和拟图图注。保留数据真正支持的判断，最后一句说明实质改动。不要读取参考修订或答案代码。

先读改稿，再用 [参考修订](reference.md) 对照。在仓库根目录运行 `python3 examples/experimental-unit/analyze.py` 可独立复算每只动物的均值、两种加权口径及主要组间差。若想严格隔离答案，只把三份输入和技能复制到临时目录；不要把整个示例目录交给受测者。

**判读改稿。** 不按措辞或格式打分。看它能否认对独立单位，按预设权重而非数据行数计算均值，分清百分比与百分点，认出组间方向如何改变，并在摘要、结果表和图注保持一致。不能凭这批描述性数据补写显著性、机制或器官功能结论。自动测试只核验数值和输入约束，不替代这一步读稿。

本地试用：一次新的独立会话只收到三份输入和科研规则、技能说明，未提供参考修订或复算程序。它从原表得到对照组 20%、处理组 24%，识别出直接合并视野会得到相反方向，并在摘要、结果、表与拟图图注中改回动物单位。该次试用没有未启用技能的对照，也没有横跨三个宿主，不能据此估计技能带来的提升。
