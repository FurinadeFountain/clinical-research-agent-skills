Lint Checks

交稿与维护阶段的 4 套自动检查脚本

由本地 Python 脚本完成固定格式、分辨率与题录核对，精简日常提示词篇幅
lint_agent_configs.py

全局规则字数预算监控 / 技能头部格式 / 全仓相对链接与脚本语法自检

lint_manuscript.py

数字引文首引顺序 / 草稿标记清理 / 标题格式 / 中英文句长与段落节奏检查

lint_figure.py

SVG / PDF 物理幅面宽高 / 嵌入位图有效分辨率（DPI） / 字号下限与字体嵌入检查

bibliography_gate.py

Zotero 入库记录与权威清单逐项回读比对 / 正文首次引用编号顺序核验
