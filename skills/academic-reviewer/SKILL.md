# 独立学术审阅（Academic Reviewer）

当**正式学术交付物**（完整论文手稿、实质性大修的核心章节、基金申请书或正式科研/数据分析报告）已经完成并准备交付，且其中的科学主张会实质影响结论解读，或用户明确要求进行独立学术审计时，启动**一次**独立内部审阅。普通对话讨论科研方法、文献阅读汇总、候选假说权衡或后续分析建议均不自动触发本审阅；常规检索、交流讨论、探索性笔记、早期草稿、环境配置与纯措辞润色同样跳过。若正式交付物新增了实验数据、分析方法或实质性修改了结论，须针对受影响范围触发审阅；仅调整排版、文字润色或沿用此前已审定的未变结论时，直接复用现有审阅结论。审阅过程优先复用既有核查证据与脚本运行结果，仅针对可能动摇核心结论的具体疑点开展抽查验证。

按以下边界启动**仅限一位、全新无历史上下文（zero-history）、只读权限**的独立审阅子代理：

- **合规审阅路径白名单**：默认通过已启用的 Codex 提供方实例调用 `OpenAI GPT` 高推理模型，或通过已启用的 Antigravity 提供方实例调用 `Google Gemini 4` 及更新代模型（若使用者在宿主补充规则 `hosts/*.md` 中显式配置了其他第一方旗舰推理模型，从其规定）。务必同时核对底层提供方（driver/provider）与模型家族本身，避免同一通道下挂混用其他厂商模型，不通过未授权第三方提供方或网页端/CLI 绕行开展本独立学术审阅。
- **多提供方宿主环境（如 T3 Code `delegate_task`）**：优先通过 MCP 跨提供方委派开展异构跨家族交叉审计——每次线程首次启动前通过 `orchestrator_capabilities` 实时核查可用提供方实例 ID 与模型 ID。从 Gemini 会话发起时，按任务重难点选用 `codex` 提供方下的 `gpt-6.2-sol` / `gpt-6.1-sol` 或 `gpt-6.2-astra` / `gpt-6-astra`（首轮排雷涉跨尺度物理/数学标度律计算、光学/工程测量物理限制、一手代表作实验与载体细节核对，或统计共线性/独立实验单位/因果识别硬伤时优先选 `sol` 系列；侧重章节递进必要性、“为什么非用该新方法不可”与宏观假说叙事取舍时优先选 `astra` 系列），设 `role="review"`，`reasoningEffort` 默认用 `"high"` 以兼顾审阅深度与响应速度，重磅首轮排雷或复杂定量推导（或用户指定时）可按需选用 `"xhigh"` 或 `"max"`；从 Codex 会话反向发起时调起 `antigravity` 下的 `gemini-4-carbon` 或 `gemini-4-argon`（设 `thought_level="high"`）。不选早于 4 代的 Gemini 或轻量 Flash-Lite/mini 变体，也不硬编码即将退线的具体日期后缀。
- **单提供方宿主或同家族自审路径**：在 **Codex 单宿主环境**下，启动一位全新无历史上下文、只读权限的同家族高推理 GPT 审阅子代理（`reasoningEffort="high"`）；在 **Antigravity 原生客户端单宿主环境**下，采用 `Gemini 4 Hydrogen`（主会话已是该模型时直接继承，否则经 `swarm` 显式指定）或不低于 Gemini 4 的合规模型启动一位全新无上下文的只读审阅子代理（显式传 `Model="inherit"` 或经 `swarm` 指定合规模型）。若宿主补充规则另有单模型审阅指定，按宿主规则执行；若白名单内无可用模型或启动失败，如实报告 `UNAVAILABLE` 及原因，不私自改换名单外模型。

模型 ID、推理选项与委派方法以本次宿主能力和工具 Schema 为准；上述名称为用户偏好，不把其他宿主参数直接照搬。宿主禁止回退或指定模型不可用时报告 `UNAVAILABLE`，不另开 CLI/网页绕行。

向审阅子代理交办时，必须明确提供：已完稿候选版本及其准确文件路径、当前文稿所处体裁与研发阶段（区分早期立项答辩稿、实操启动设计书与完稿论文）、核心科学问题与拟确立主张、约定的任务范围及本轮改动内容、关键一手文献及重要脚本/执行记录、已知证据缺口以及只读权限边界。针对修订稿，务必附上修订前原文或 diff 差异：即使未增补任何新数据，删去或泛化一个比较条件、测量参照、模型假设或不确定度限定，也同样可能彻底改变核心论断强度。同时将 [学术审计细则](references/audit-rubric.md) 交予审阅子代理，明确要求聚焦动摇主结论或因果识别的硬伤，不得向摘要、立项依据或核心论点句索要防御性技术补丁；审阅者必须直接核查核心证据文件、严守只读边界且不得继续衍生孙代理。

在 `scientific-drafting` 统筹重大起草与重构任务时，可安排一位学术审阅者与一位科学编辑审阅者在同一固定候选稿快照上独立并行阅读。二者均维持只读并各自定位受影响结论与关联依赖位置，由唯一主笔汇总整合修改。上述分工严格守住科学核查边界，不将学术审阅扩展为文风偏好挑刺，也不重复配置多余审阅者。

审阅子代理依细则结构化返回裁决等级、覆盖范围、信息缺口与实质性缺陷。若审阅结果缺失、格式残缺、执行报错或意外中断，一律按 `UNAVAILABLE` 记录上报，绝不视为“审阅通过”。主代理收到回报后逐条核实发现，严格执行**“1 轮全审 ＋ 条件触发的至多 1 轮局部复核”封顶**与**三级分流漏斗**，清晰记录每条意见的最终状态（已修正 / 已分流落位 / 凭据不改 / 尚待解决）：
1. **一级（重塑因果主线与递进必要性的实质硬伤）**：如物理/生理标度方向错误、平台互补逻辑缺环、对照基线时序失洽、代表作给药/测量混杂或回归共线性错误，直接重构进正文主干以锻造核心判别支点（越界断言则优先删词收紧）。
2. **二级（有实质防漏价值的方法质控、误差边界与退守判据）**：按 [共用落位原则](../scientific-prose/SKILL.md#条件保留与细节落位) 集中至方法/统计专节，按课题阶段分流至 `Backup` 或 `SOP`；决定结论成立或图表独立可理解的条件就近保留，不删必要限定，也不多处刷技术补丁。
3. **三级（三阶极端失败分支与注册试验级过度防漏）**：如对后备方案再套后备方案或细枝末节的多重比较族切分，直接归入“凭据不改”并在交付说明中透明列明。

若首轮仅涉措辞收紧、概念归位或二级单点补漏，主笔修完即闭环交付（**1 轮封顶**）；仅当首轮检出一级硬伤并触发**实验控制逻辑反转、平台递进分工重塑或核心统计模型重构**时，允许仅针对**重构片段**追加 **1 轮**定向复核（总计硬封顶 **2 轮**），**严禁以追逐 `0 FAIL, 0 WARN` 为停机条件**。对未能消除的残余疑点如实披露，主代理对所交范围内的最终科学严谨性承担全部责任。
