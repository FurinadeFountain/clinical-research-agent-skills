# 幻灯片制作与交付

由一位主代理统筹权威幻灯片源，将叙事推进、模板继承、原生可编辑对象保真与快速交付对齐；尊重用户指定载体、模板、来源与既有工具链。默认将视觉排版目视检查交由用户完成，AI 专注源稿构建与秒级程序化校验，不默认执行耗时渲染或桌面往返检查。

## 先选任务范围

读取当前请求、现有文稿、模板文件与最新更正，明确汇报受众、语言、时长/页数约束、主讲与备答切分、交付路径及必须保留的对象；仅针对改变制作决策的缺项提问。

| 任务类型 | 执行范围与路由 |
| --- | --- |
| 局部改字、微调对象位置或样式 | 主代理读取目标对象及必要邻页直接修改，仅运行秒级结构自检并保留未改设计 |
| 新建全套、跨页重构或更换模板 | 加载 [讲述与范围](references/story-and-scope.md) 与 [模板与原生对象](references/template-and-native.md)，由主代理直接完成构建与结构自检后交付；仅当用户明确要求独立审阅时再按 [协作规范](references/collaboration.md) 增配只读审阅者 |
| 单页新增或有限章节修订 | 主代理完成制作、程序化校验并直接交付 |
| 审阅既有 PPT 或排查兼容性故障 | 当前代理以只读方式检查实际文件（按需渲染目标页）及必要来源，清晰列出缺陷与未核范围 |
| 格式转换、保存或播放故障修复 | 仅针对故障点核查对象保真、页面呈现及播放状态，并复用既有内容审阅 |
| 解读幻灯片内容、润色讲稿或制作独立科学图 | 转交对应说明/行文（`scientific-prose`）或制图（`scientific-visualization`）流程 |

涉单位、实验对比、核心结论或跨页叙事调整的局部修订按实质变更复核前后依赖。新建中文或双语学术幻灯片未指定模板时，优先选用用户本地配置的机构学术 Beamer 模板技能。

## 制作与轻量校验

1. **前置明确每页任务与继承对象**：新建或重构先梳理页面推进关系；套用模板时提前读取真实母版、版式占位符与原生组件；局部调整仅读取关联对象。
2. **控制构建粒度与脚本解耦**：将生成 `.pptx` 的构建脚本与可选的 PDF 导出/渲染脚本分开执行，严禁把慢速 LibreOffice 渲染或 GUI 往返检验串在构建命令后拖入后台长任务。
3. **默认仅做秒级确定性自检**：对照 [核验表](references/checks.md) 执行默认必检项（构建退出码为 0、成品文件已更新且非空、纯 Python/XML 内存级结构自检通过——可正常重新读取、页数与隐藏属性正确、无负宽/负高几何、图像与资源引用有效；若改动了独立自绘科学图则对受影响图件运行 `lint_figure.py --mode slide`）。
4. **重型核验默认关闭、严格按需触发**：**默认不执行** LibreOffice/PowerPoint 导出 PDF、逐页渲染 PNG、AI 逐页看图目检（`V1`）、桌面版 PowerPoint 打开—保存—关闭—重开往返核验（`D4`）或自动拉起审阅子代理。仅当用户明确要求“同时导出 PDF”“帮我渲染检查排版”或“排查 PowerPoint 打开报错/修复弹窗”时才按需执行对应项。
5. **统一回写并闭环依赖**：主代理更新权威源稿，同步本次请求范围内的讲稿、备注及交叉页码。

## 完成与交付

构建与秒级结构自检通过后**立即交付**已保存权威文件（及用户明确要求的导出版本）的精确 `file://` 路径与简洁改动清单，将最终视觉版式检查交由用户完成。

**防卡死硬约束**：严禁在尚未给出成品文件路径的情况下，以“正在等待后台 PDF 导出/逐页渲染核验完成”结束回合；若用户确需同步导出 PDF，先确保 `.pptx` 已落盘并在同一轮内拿到结果或明确交出已落盘文件路径后再结束。存在音视频媒体的页面按需确认资源嵌入/链接关系。科研正文起草与全面审计沿用 `scientific-drafting` 与 `academic-reviewer`；维护本技能自身评测时阅读 [行为测试](references/evaluation.md)。
