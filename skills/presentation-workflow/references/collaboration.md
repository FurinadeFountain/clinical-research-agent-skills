# 分工与改动传播

用于整套构建、模板迁移或独立复核；主代理作为唯一写入者负责统筹与交付。

| 任务类型 | 最小协同配置 |
| --- | --- |
| 局部改字/调位、简短文稿或定向导出 | 主代理独立制作并核验受影响页与输出文件 |
| 新建全套、跨页重构或更换模板 | 主代理 + 一位独立只读演示稿审阅者，统筹核查讲述、模板、视觉呈现与交付项 |
| 与排版相互独立的密集文献/数据核查 | 确有并行增益时增派一位有边界内容核查协作者 |
| 只读排查既有文件缺陷 | 当前代理直接只读审阅并汇报具体问题与未核范围 |
| 达标正式科研交付物审计 | 直接复用或调用 `academic-reviewer`，演示审阅聚焦载体与呈现质量 |

协作者保持父会话模型与提供方；委派前说明分工，同稿不可并行编辑或递归派生子代理。审阅者接收固定候选文件、实际渲染页、最新要求、模板与核查边界，基于实物逐项审看并返回精确页码、缺陷影响、最小改法及未核范围。主代理优先跑通复杂代表页后再铺开同类页面，核实意见后统一修订。

| 变动范围 | 需同步回查的对象与页面 |
| --- | --- |
| 标签文案、坐标位置、字色或字号 | 指定原生对象、邻近图文间距、所在页实际渲染及对应图例编码 |
| 数值、单位、实验比较或结论 | 一手源数据/文献、关联论证页、图表、演讲备注及讲稿（必要时交原科学审阅复核） |
| 调整页序、主讲/备答划分或增删页 | 内部导航跳转、隐藏属性、页码引用、备注/讲稿对齐与前后过渡 |
| 更改母版、主题、字体或公共版式 | 继承该母版的全部页面 |
| 科学图件更新或局部放大 | 源图文件、比较与空间关系、标注连线及 `scientific-visualization` 验收结果 |
| 图表或表格底层数据与结构 | 数值序列、分类轴、行列结构、工作簿链接、原生编辑性及对应解说 |
| 兼容性修复或切换导出工具 | 对象与关联保留、受影响页显示、隐藏页/备注/跳转/媒体及原生软件重开表现 |
| 导出 PDF 或另存副本 | 权威源一致性、实际输出页面渲染与请求功能验证 |

简单定点的修改由主代理直接闭环检查；遇未决争议或影响全局叙事/科学前提的变更时，发回原审阅者定向复查受影响范围后即收尾交付。
