# 分工与改动传播

主代理作为唯一写入者负责统筹、构建、轻量校验与直接交付。默认由主代理独立完成，**不自动增配**只读演示审阅子代理，避免额外渲染与多轮等待。

| 任务类型 | 默认配置 |
| --- | --- |
| 局部改字/调位、单页新增、简短文稿或定向导出 | 主代理独立制作、秒级结构校验并直接交付 |
| 新建全套、跨页重构或更换模板 | 默认主代理独立完成制作与交付；仅当用户明确要求独立全套审阅时，再增配一位只读演示审阅者 |
| 与排版相互独立的密集文献/数据核查 | 确有并行增益时可增派一位有边界内容核查协作者 |
| 只读排查既有文件缺陷 | 当前代理直接只读审阅并汇报具体问题与未核范围 |
| 达标正式科研交付物审计 | 复用或按触发条件调用 `academic-reviewer`，不叠加演示审阅子代理 |

确需增配协作者时，保持父会话模型与提供方；委派前说明分工，同稿不可并行编辑或递归派生子代理。审阅者严格只读，基于固定候选文件与指定核查边界返回精确页码、缺陷影响、最小改法及未核范围，主代理核实后统一修订并立即交付。

| 变动范围 | 需同步回查的对象与页面 |
| --- | --- |
| 标签文案、坐标位置、字色或字号 | 指定原生对象、邻近图文边界坐标及对应图例编码 |
| 数值、单位、实验比较或结论 | 一手源数据/文献、关联论证页、图表、演讲备注及讲稿 |
| 调整页序、主讲/备答划分或增删页 | 内部导航跳转、隐藏属性、页码引用、备注/讲稿对齐与前后过渡 |
| 更改母版、主题、字体或公共版式 | 继承该母版的页面占位符与样式引用 |
| 科学图件更新或局部放大 | 源图文件、比较与空间关系、标注连线及 `lint_figure.py --mode slide` 结果 |
| 图表或表格底层数据与结构 | 数值序列、分类轴、行列结构、工作簿链接、原生编辑性及对应解说 |
| 兼容性修复或切换导出工具 | 对象与关联保留、隐藏页/备注/跳转/媒体，必要时再做目标页渲染或原生重开 |
| 用户要求同步导出 PDF 或另存副本 | 权威源一致性与请求输出文件的完整落盘 |

常规修订由主代理在对象层与源码层闭环检查后直接交付路径，不启动额外复核循环。
