# 模板、原生对象与目标应用

用于修改既有幻灯片或套用真实参考模板。明确模板、内容源与风格参考的各自归属；操作指定模板时先读取实际文件，再基于已有结构编辑。

## 资产与原生结构继承

- **完整继承模板特征**：启动前核实页面尺寸、母版/版式继承、主题色、字体、混合文本框样式、页眉页脚、标识、导航、背景、图像比例/裁切与代表页；局部改字保留原有公共母版，调整母版或公共元件时同步排查继承该母版的页面。
- **保留精细对象形态**：逐文字段与段落维持混排文本框格式；保留图像有效分辨率、原始宽高比、比例尺与关键裁切视野；科研图像像素修改或重绘严格按授权范围处理。
- **保持原生可编辑性**：需后续编辑的正文、标注、表格、统计图表与流程图连接线均维持原生可编辑对象（图表保留源数据序列与工作簿关联；无字底图配合原生叠加标签时准确写明各自编辑范围）。连接线端点贴合对应节点，确保几何参数无负宽/高异常。
- **同步保留隐藏与媒体关系**：在对象引用与 XML 结构层面核对隐藏页显示状态、演讲备注、超链接跳转及音视频播放设置。

## 原生保存、兼容与故障排查

优先采用最能完整保留源对象的原生编辑器或程序接口处理对应格式。日常新建、重构与改稿完成构建及内存级 XML/几何自检后即可直接交付 `.pptx`，**默认不启动**桌面 PowerPoint 执行“打开—保存—关闭—重开”往返核验。

仅在**排查 PowerPoint 修复警告/兼容性故障**，或**用户明确要求桌面软件验收**时，再于 PowerPoint 中执行打开—保存—关闭—重开流程（保存测试副本时保持版本对应且勿关闭无关用户文档）。如遇修复警告，并排比对故障原稿与修复后副本定位具体 XML 关系、生成器几何误差或媒体引用错误，修正权威源后重验输出。
