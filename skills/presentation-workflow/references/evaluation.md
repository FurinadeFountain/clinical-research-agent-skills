# 技能维护时的行为测试

仅在维护或评测本技能时读取。使用真实任务留存的返工前 PPT、原模板与必要素材构造隔离测试副本，登记原路径哈希、任务请求与输出，以实际原生 PPT 文件及渲染页作为对照依据。

至少配对运行两类基准案例：一项在既有旧稿上的只读缺陷排查（检验真实硬伤检出、误报率与未核范围诚实度），一项在稳定模板上的有界局部修订（检验目标变动落位、未改对象与媒体/备注保真以及相关页显示）；另辅以边界触发案例（如仅解释内容、只润色讲稿、重画独立科学图或更换公共母版）。

向全新测试执行者仅提供现行技能文件、真实请求与精简原材料，由其自主路由所需参考模块，遇环境缺失原生应用时如实披露。面向观察到的实际失效做精准窄修，对比完整返工耗时、首轮遗漏与最终渲染结果以确认改进实效。
