# 幻灯片逐项核验

根据任务边界选取适用核验项。新稿或全套改版覆盖全部交付页；局部修改核查受影响页面与关联依赖，并通过对象/文件差异确认未改内容完好。逐项在上下文保留 ID、状态（**已核 / 待修 / 未核 / 不适用**）与简短位置依据；局部已确认部分拆分子项分别记明。

| ID 与适用情景 | 核心核验内容与证据依据 | 责任与时点 |
| --- | --- | --- |
| R1 — 全部交付任务 | 任务目标、语言、页数/时长、主讲/备答范围、输出路径与用户最新修正一致 | 主代理 / 开始前 |
| C1 — 新稿或讲述重构 | 各页主旨、先后过渡、实验对照及发现推进清楚；标题准确概括正文且讲稿补充读图 | 主代理或审阅者 / 骨架与终稿 |
| C2 — 科学事实或数据变化 | 对象、条件、比较、方向、时程、单位、数值及归属与一手来源一致，复用既有科学审阅 | 主代理 / 依据来源核对 |
| T1 — 现稿编辑与模板适配 | 对照参考母版检查尺寸、主题配色、字体、混排文本框样式、页眉页脚、标识与图像裁切 | 主代理 / 制作前及受影响页 |
| T2 — 原生可编辑对象 | 核查并确认文字、标签、表格行列、图表数据工作簿及流程图连接线维持原生可编辑对象（区分位图底图与原生标注） | 主代理 / 对象层及目标应用 |
| F1 — PPTX 生成与排错 | 校验包内 XML 关系、资源引用与图形几何有效性（修复负宽/高导致的对象丢失或损坏），保留模板特例设计 | 主代理 / 结构工具与页面核查 |
| V1 — 版式或输出变更 | 检查预定投影/阅读尺寸下的实际逐页渲染：换行、裁切、比例、字号、对比度、图像锐度、留白与页码清晰度 | 主代理或审阅者 / 渲染图像 |
| V2 — 科学图件与机理图 | 核实图中分组对比、解剖定位、标签指代、箭头方向与比例尺保留，对接 `scientific-visualization` 核验结果 | 主代理 / 图源与实际页 |
| D1 — 备注、讲稿与双语 | 当前页序、每页备注、独立讲稿及双语版本严密对应，写入前重读最新源稿以保留手动批注 | 主代理 / 保存前后回读 |
| D2 — 页序、导航与隐藏状态 | 核对幻灯片 ID、显示/隐藏属性、主讲与备答区隔、内部跳转锚点与超链接有效 | 主代理 / 原生关系验证 |
| D3 — 媒体嵌入与播放 | 核实音视频嵌入/外链路径、触发设置、播放进度及实际声画出力（未改媒体可复用既有结果） | 主代理 / 实机播放 |
| D4 — 原生 PowerPoint 兼容 | 在 PowerPoint 中执行打开、保存、关闭、重开，核实零修复提示、零静默丢字及对象可编辑 | 主代理 / 原生应用（不可用记未核） |
| D5 — 最终保存与文件交付 | 核对权威源文件、请求生成的 PDF/PPTX/讲稿对应一致且入口正常；按真实对象及内容差异核验 | 主代理 / 终稿交付前 |
