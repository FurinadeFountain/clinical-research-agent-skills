# 幻灯片核验清单（默认轻量 + 按需重检）

按任务边界分层执行，避免用慢速渲染与桌面往返阻塞交付。默认流程仅跑**秒级程序化自检**；重型导出、逐页渲染看图与桌面软件往返检验均设为**按需触发**。

## 一、默认必检项（秒级、无渲染、无 GUI）

| ID 与适用情景 | 核心核验内容与证据依据 | 责任与时点 |
| --- | --- | --- |
| R1 — 全部交付任务 | 任务目标、语言、页数/时长、主讲/备答范围、输出路径与用户最新修正一致 | 主代理 / 开始前 |
| C1 — 新稿或讲述重构 | 各页主旨、研究趋势、创新与价值要件、步间递进衔接及实验对照清楚；主讲用陈述标题、备答用学术直问标题；核查页内无咨询腔缩略词、过程自证词与过强断语 | 主代理 / 骨架与定稿 |
| C2 — 科学事实、物理模型或数据变化 | 对象、条件、比较、方向、时程、单位、数值及归属与一手来源一致；跨页重复出现的同一物理过程、几何构型或力学模型在相态位置、运动方向、受力矢量与因果分支上严格自洽 | 主代理 / 依据来源与跨页核对 |
| T1 — 现稿编辑与模板适配 | 对照参考母版检查尺寸、主题配色、字体、混排文本框样式、页眉页脚与图像裁切逻辑 | 主代理 / 制作前及受影响页 |
| T2 — 原生可编辑对象 | 确认文字、标签、表格行列、图表数据工作簿及流程图连接线在对象层维持原生可编辑 | 主代理 / 对象层脚本校验 |
| F1 — PPTX 生成与排错 | 内存级校验包内 XML 关系、可重读性、资源引用与图形几何有效性（无负宽/高、无断链） | 主代理 / 秒级结构脚本 |
| V2 — 科学图件与引用原图 | 核实图源对比、标注与比例尺；引用原始显微或成像图件的关键通道、相态与边界具备直白可读标注；改动独立自绘矢量图时跑 `lint_figure.py --mode slide` | 主代理 / 涉及图件时 |
| D1 — 备注、讲稿与听觉语体 | 当前页序、每页备注、独立讲稿及双语版本对应一致，写入前重读源稿保留手改；按听众听觉视角核查无平面方位导引词、防御性开场与照念页面，且封面署名与口播口径按约定区分 | 主代理 / 保存前后 |
| D2 — 页序、导航与隐藏状态 | 核对幻灯片 ID、显示/隐藏属性、主讲与备答区隔、内部跳转锚点与超链接关系 | 主代理 / 原生 XML 校验 |
| D5 — 最终保存与文件交付 | 确认权威源文件（及用户请求的导出文件）退出码为 0、非空且时间戳已更新，直接给出精确 `file://` 路径 | 主代理 / 终稿交付前 |

## 二、按需重检项（默认关闭，仅用户明确要求或排查故障时启用）

| ID 与触发条件 | 核心核验内容与证据依据 | 责任与时点 |
| --- | --- | --- |
| V1 — 用户明确要求渲染检查排版，或只读排查视觉缺陷 | 仅对目标页（避免无差别全量重渲染）导出并检查换行、裁切、重叠、字号、对比度与页码清晰度；渲染产物须先写临时目录并校验后再原子替换发布，待渲染进程退出后再读图 | 主代理（或应要求增配的审阅者） |
| D3 — 页面新增或修改音视频媒体 | 核实音视频嵌入/外链路径、触发设置；仅在排查播放故障时做实机声画验证 | 主代理 / 按需实机核验 |
| D4 — 排查 PPTX 修复弹窗或兼容性故障，或用户明确要求桌面验收 | 在 PowerPoint 中执行打开、保存、关闭、重开，核实零修复提示、零静默丢字及对象可编辑 | 主代理 / 原生应用（不可用记未核） |
