# 科学编辑审阅

本技能负责提升科研文稿的论证严谨度与读者理解连贯度，把科学事实、方法细节、数值与引文真伪的核查留在专门审校流程。具体修辞、去 AI 味、标题规范与解释完整性对照 [科研行文与润色](../scientific-prose/SKILL.md) 与 [简洁而完整的研究解释](../scientific-prose/references/complete-research-explanations.md) 直接实施，交付用户要求的具体改稿。

## 选择审阅关注模式

- **提纲阶段**：核查中心问题、各节论证增量、必要前提位置、证据落点及向核心结论推进的顺畅度；准确识别尚缺支撑的跳跃。若为基金申请书或研究计划，参照 [基金申请书体裁规范](../scientific-drafting/references/genres/proposal.md) 聚焦核查“问题与工具对称性”“特异性主张与判别对照配对”“结论与实测认知层一致”及核心“概念—干预—读出”主链，**暂不催讨**仪器标定参数、伪影扣除或统计先验方差细算等早期技术枝节。
- **成稿阶段**：以连贯通读方式审查固定候选稿的完整论证链、读者认知推进与**主线净度**，将标题、表格、图注与段落收束纳入同一视角，检验观察事实、限定条件、对比设计与机制推论是否合围出清晰说明。重点核查四项：（1）**立意、临床锚点与体裁路标**——医学与生物学标书/选题稿须确认摘要、标题与开场锚定在具体临床判别或病理生理规律而非纯方法学定标/排混，并执行**无文献首读检验**（遮住参考文献后，仅凭标题与开场数句须能清晰认出所挑战的临床模式/实践及核心物理或生理反转机制，严防为防超卖而过度去标签化，落实“临床借势、实验收口”）；命题议论文（Tutorial Essay）与观点评论须确认引言末句立起中心论断、各主节末尾保留扣题小结；（2）**主线相关性裁剪**——未直接检验核心自变量的外围通路文献压缩为半句至一句过渡；（3）**反生造词与句法负荷**——排查硬译审阅黑话或生造复合名词（如“实验参照腔室”“双级解耦”“名义检出尺度”）、中文靠分号与长定语拼成的百字代码式防御长句，以及英文段尾连续堆叠孤立免责短句造成的电报式顿挫；（4）**审后重排闭环**——合入学术审阅意见或大幅删压后，导出前须基于最终稿复读衔接。
- **定向复核**：修订合入后集中复查实际改动处、依赖其前提的邻接上下文及争议重叠段；仅当波及范围外出现实质影响时才扩大核查半径。

三者属于按任务切换的审阅重点，按需选用最小有效编制。在多提供方宿主（如 T3 Code `delegate_task`）下，确需外派独立只读编辑时先经 `orchestrator_capabilities` 核查并严守提供方与模型家族对齐原则（避免经单一通道混挂其他厂商模型，如不经 `antigravity` 调用非 Google 模型）：**提纲/全稿论证结构、立意与主线净度审阅**优先派只读 `codex` `astra` 系列（如 `gpt-6.2-astra`，`role="review"`, `reasoningEffort="high"`）以对冲主笔叙事过顺或包装过猛的盲区；纯**读者理解与汉语流畅度**核查沿用 `antigravity` Gemini 4 或由主笔自查。单提供方宿主下沿用当前会话合规模型（`Model="inherit"` 或 `swarm` 默认继承）。

## 固定候选稿与最小编制

**默认由主笔本人通读自查，不自动派生独立编辑子代理，也不与 `academic-reviewer` 默认并行叠加。** 仅当用户明确要求额外编辑审阅，或超长文稿确实存在互相独立且单代理难以兼顾的注意力瓶颈时，才增派至多一位只读编辑（确需拆分“全局论证”与“读者理解”双视角仅限明确要求或特长全稿重构）。

确需并行交办时采用 [科研起草协作短准备与原新对照](../scientific-drafting/references/collaboration.md#短准备与原新对照) 机制，直接交付固定稿本、审阅范围、核心证据锚点与已确认配对记录。所有审阅者严格只读且独立完成首读，仅回报有凭有据的实质问题（包含**精确位置、判断依据与对读者/论证的影响、最小可行改法及依赖范围**），清楚分开逻辑硬伤与纯属文风偏好，并将“已核范围内未发现实质缺陷”及“因缺材料而未核范围”作为正常结论如实写明。主笔作为唯一写入者裁决并更新权威源稿，完整保留用户手动批注与双端同步规范。

## 整合修改且不丢失解释

以真实科学依据填补逻辑断层，不靠顺滑连接词掩盖前提缺失或机制跳跃。精简文字时完整保留支撑“某发现如何推导至核心结论”的条件、变化方向与关键不确定度，防止正文退化成互不关联的事实堆砌。

采纳删减建议前，先划定互相替代或互为前提的**关联依赖范围**统一裁断：当两位审阅者各自以“另一处已写”为由建议删除同义陈述时，必须基于叠加改动后的新版全文核查，确保关键前提至少在最合适的落位完整保留。

若编辑或润色触及科学事实、对照设定或结论强度实质变更，按触发条件转交 [Academic Reviewer](../academic-reviewer/SKILL.md) 开展一次科学审计；科学核查改稿后由主笔本人通读邻文闭合衔接即可，**不自动退回编辑子代理再跑一轮**。作用域内关键缺陷修复完成、依赖邻文通读通过即收手交付，并在最终回复中简明列出实质遗留局限与实际审阅覆盖范围。
