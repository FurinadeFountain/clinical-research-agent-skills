# Zotero 核验型参考文献管理

通过既有的 Zotero 集成工具、Pyzotero CLI 或受支持的 Zotero API 执行文库操作，围绕既有文库与权威稿件开展题录校验和引文导出。

## 范围与检查点

- 明确目标文库与集合、待执行操作、对应手稿版本及引文格式。默认操作用户个人文库；涉及共享组库须获得明确范围授权。仅要求核对或比对时保持只读检视并交付差异报告；获授权修改指定条目时直接落实更新。
- 修改任何条目之前先读取现状，沿用稳定的文库 ID 与条目标识键（item key），并完整保留无关的集合归属、标签、附件、PDF 批注与笔记；大范围重组前先做备份，小批量修订保留重点前后对照证据。
- DOI 或题名匹配仅确立文献身份一致，其余题录字段须逐项核查后方能放行；汇报核查结果时清晰区分四项状态：**身份已核**、**元数据已核**、**PDF 附件已备**与**正文科学论断已核**。

## 条目导入与元数据修复

1. **查重识别。** 综合检索 DOI、PMID、ISBN 与完整题名以确认库内状态。规范标识符前缀与大小写后保留原值，存在多条候选时全部保留；严格区分预印本、正式发表版（version of record）、勘误与撤稿记录。
2. **对照权威来源逐字段核查。** 优先核对出版商论文页面或摘要页及权威题录记录，遇缺失或冲突字段时引入第二权威来源交叉验证；记录实际采用的录入途径（Connector、DOI 解析、PDF 识别、RIS/BibTeX 或 JSON API）。核查条目类型（`itemType`）、题名、按顺序排列的个人/团体作者、发表日期与发表状态；期刊论文额外核查刊名、卷号、期号、起止页码或文章编号；图书、章节、预印本相应核对版次、出版社、ISBN、编者、章节页码或仓储版本。确实尚未分配（如 online-first）或不适用的字段留空并写明理由，按出版页面如实区分在线发表日期与正式期卷。
3. **准备可比对的预期载荷。** 事先保存预期写入字段、支撑来源位置、目标文库/集合以及匹配/新建标识键。预期值须直接取自权威题录来源并独立于写入接口返回值。完整保留作者姓名后缀与变音符号、团体作者全称、电子页码前缀与文章编号，拦截缺位数字、作者顺位错乱与起始页码偏移。
4. **分批写入与回读核验。** 使用受支持的工具或 API 开展有界批处理并传入版本前置条件；新写入路径先通过小批量代表样本验证。写入后按返回的新旧 key 逐条重新 `GET` 拉取入库记录，逐字段比对全部提交字段以及预期集合、标签、附件与笔记完整性。
5. **出现偏差立即熔断所在批次。** 完整保留预期载荷、写入响应与新 `GET` 回读快照；对可能已部分成功的新建请求先按返回 key 或标识符对账防重，再在授权范围内修正受影响条目。日志中严格隐藏 API 密钥与鉴权请求头。

使用 [核验清单与只读门禁脚本](references/manifest.md) 开展确定性校验；该脚本保持严格只读，写入操作由既有工具完成。

## 按文稿顺序生成与比对参考文献

1. 通读当前实际定稿（含纳入范围的图注、表注与补充材料引用），梳理唯一文献集合与指定格式下的排序规则。顺序编码制（如 Vancouver）严格采用**正文首次引用顺序**，将项目内部文献编号与文中显示序号分别保存，并在导出前解决未匹配、重复计号或指向不明的引文。
2. 记录待比对手稿的文件快照/哈希与有序条目映射表（区分背景阅读集合与正文实际引用集）。复核关键条目元数据，并在影响结论时刷新撤稿、勘误或正式见刊状态。运行 `scripts/bibliography_gate.py` 校验字段一致性，一手来源核查仍由权威记录负责。
3. 由 Zotero 或标准 CSL 引擎生成参考文献文本：随技能附带的导出器适用于**顺序编码、按首次引用排序**体例（清单中显式声明 `numbering: citation-order`）；著者—出版年制或字母排序体例交由完整 CSL 处理器依目标样式生成。
4. 逐项核对作者、期刊缩写、年份/日期、卷期、页码或文章编号、DOI/URL 以及文内编号与文末列表的一一对应，区分底层数据缺误与 CSL 格式排版规则，使用官方 NLM 清单核实后的刊名缩写再作相应标注，同时保留准确 style、locale 与原始格式化输出。
5. 任一必检项未通过时立即生成差异报告；如需查看原始导出草稿，显式标为 **unverified（未通过核验）**。获授权后在 Zotero 源记录中修正字段并重新导出复跑门禁，保持数据库与导出文献表同源。
6. 更新手稿正文任务须回写权威文稿、同步快照并回读核对；仅比对或导出任务交付导出表与差异报告（按项目需要同步至 Notion 页面），并明确报告核对条数、实际修正项、尚存未决字段与真实核验范围。

## 工具与接口要点

- 优先运行既有 Zotero 工具状态检查。Pyzotero 适合精准 DOI 检索与显式集合成员管理，Zotero Local API 适合结构化读取；10+ 版本在已有本地写授权、实例 ID 与版本前置条件齐备时支持写入，旧版不能据此写入，常用本地接口路由见 [本地 API 路由参考](../zotero/references/local-api-routes.md)。
- 导出文献条目优先请求 `/items/top` 过滤笔记与附件子对象；`include=bib` 返回格式化单条文献，`citation` 返回文内引文标注；含跨条目消歧或同作者缩略规则的体例须整组交由 CSL 引擎生成。
- 门禁脚本负责校验数据库存储记录与预期清单的一致性，文献来源真伪及对正文科学论断的支撑仍由一手全文核查负责。
