# 科研绘图与视觉审查

按最终交付场景的 **1:1 真实物理尺寸**（期刊论文版心栏宽、幻灯片可用内容框或海报/图文摘要版框）制作出版级科研图件，清晰传达生物学、临床或生物力学关系。由一位主制作者统一维护唯一权威源图与代码，核实数据到视觉映射的真实性，先通过确定性静态门禁再目视检查实际渲染输出。

## 适用范围与任务分流

| 请求类型 | 执行路径 |
| :--- | :--- |
| **局部微调（科学含义不变）**：修改单个标注、配色、字号、对齐或局部缺陷 | 仅在既有源文件内编辑目标对象，重新导出后运行 [lint_figure.py](scripts/lint_figure.py) 并检查受影响局部及紧邻排版依赖。不重构无关分图、不增派子代理、不重审未改动内容。*（一旦修改标签导致单位、比较组、分母或论断强度改变，按实质性数据变动处理。）* |
| **新建图件或实质性重设计** | 先锁定目标投放媒介与 1:1 物理尺寸，结合真实数据与文献来源先规划**整幅图的完整科学结果故事链与模块化叙事结构**（针对 `6–12+` 多子图整页图明确叙事行带、主次锚点、三级留白间距与各子图职责）；在单面板内部对多维耦合关系对照 [高阶复合图谱与进阶包工作流](references/advanced-chart-archetypes.md) 评估升维形态，整图构图、排印与视觉验收联合遵守 [排版设计与标注偏好](references/design-preferences.md)、[配色方案与视觉编码](references/color-palettes.md)、对应领域指南及 [图件审核门禁](references/figure-review.md)。 |
| **仅请求图件评审或诊断** | 严格保持只读。有 SVG/PDF 源图时运行 [lint_figure.py](scripts/lint_figure.py)；仅有截图/位图时只做可见范围诊断，明确字体与矢量结构未核，不要求用不支持的格式硬跑脚本。再对照 [排版设计与标注偏好](references/design-preferences.md) 与 [图件审核门禁](references/figure-review.md) 检查渲染成图与已有源码/数据，给出可落地的缺陷定位与修复建议，不改写源文件，也不额外衍生审阅代理。 |
| **不属于本技能范畴** | 纯图意解读、仅修改图注文字（归 `scientific-prose`）或一般幻灯片/网页版式编排（归 `presentation-workflow`），除非需在其中新建或编辑科研图件本身。 |

## 媒介物理尺寸与字号预设

**落笔写任何坐标前先锁定目标媒介与 1:1 物理预设。** 严禁使用宽松随意的大画布（如 `figsize=(12, 10)`）草率成图后再指望插图时整体缩放。若目标期刊、幻灯片母版或用户明确给出尺寸规格，以实际指定为准。下表中的尺寸、字体、语言、字号和编号样式为个人默认预设，不是普适科学标准；用户/项目/期刊要求可覆盖，无需重复确认。数据、单位、分母、独立样本和编码真实性不因样式覆盖而放宽。

| 交付媒介预设 | 画布 / 置入物理尺寸 | 字体排印与分图编号 | 线条权重与坐标轴框 |
| :--- | :--- | :--- | :--- |
| **期刊论文 / 基金申请书 / 正式研究报告（未指定时默认）** | **单栏**：`85–89 mm`（`3.35–3.50 in`）；**1.5 栏**：`114–136 mm`（`4.49–5.35 in`）；**双栏**：`174–183 mm`（`6.85–7.20 in`）；**整图最大高度**：`170–200 mm` | **Arial**（或 Helvetica），配套数学符号用 **Latin Modern Math**。坐标轴题、刻度值、图例与机制图标注一律用 **`6–7 pt` Regular**（上下标硬底线 `5 pt`，不加粗轴标题）。多栏拼图每分图左上角外侧仅放独立的 **`8 pt` Bold** 正体分图编号 `A, B, C, D`（投 *Nature* 系列改用小写 `a, b, c, d`）；禁止给编号后缀子图标题（禁用 `A  Arterial pressure`）；仅当同型兄弟子图需区分实验条件/模态/基因时使用 `6–7 pt` Regular 简短条件标签。 | 去上右边框的洁净坐标轴（`0.5–0.75 pt`，`#222222` 或纯黑，默认关闭背景网格线除非读数必需）；主数据曲线与主要轮廓线 `0.75–1.25 pt`。 |
| **学术幻灯片（`presentation-workflow` 及机构自定义 Beamer 模板）** | 先读取对应幻灯片的**实际可用内容框尺寸**，不把论文版面直接硬缩或拉扁套用。**16:9 Beamer**（整页 `160 × 90 mm`）：常用图框约 `135–148 × 55–68 mm`。**宽屏 PPTX / Keynote**（整页 `338.7 × 190.5 mm` / `13.33 × 7.5 in`）：严格按页面预留置入框宽高出图。 | **16:9 Beamer**：常规标注 `8–10 pt` Regular（上下标 `>=7 pt`）。**宽屏 PPTX/Keynote**：常规标注 `14–18 pt` Regular（上下标 `>=12 pt`）。字体与当前幻灯片保持一致（`Source Sans 3` / `Source Han Sans SC` / `KpMath Sans`，否则退用 Arial/Helvetica）。除非汇报时需口头点指各分图，否则省去论文式 `A, B, C` 编号；精简文字与分图密度以适配投影远观，并与幻灯片背景协调。 | **16:9 Beamer**：坐标轴 `0.8–1.1 pt`，主曲线 `1.2–1.8 pt`。**宽屏 PPTX**：坐标轴 `1.0–1.5 pt`，主曲线 `1.5–2.5 pt`。同样去掉上右冗余轴线，按需克制使用网格。 |
| **学术海报 / 图文摘要 / 特定场合** | 动笔前先锁定实际张贴或嵌入框的精确宽高。 | 按实际物理阅读距离等比设计常规字号（`Regular`）与视觉层级。 | 坐标轴与主通路/数据线宽随实际画布宽度等比例缩放。 |

- **画布文字洁净度**：图内标注默认使用英文（除非幻灯片或投稿载体规定中文）；图注随正文语言一致。论文正文图画布内不放整图总标题、副标题、横幅标签或右下角防御性免责小字，除非用户明确指定保留。
- **导出格式与字体嵌入（通用要求）**：数据图与矢量机制图导出可编辑矢量 **PDF / SVG**，并强制嵌入可检索可编辑字体（`pdf.fonttype = 42`、`ps.fonttype = 42`、`svg.fonttype = 'none'`）。嵌入显微成像、CT、MRI、超声或三维渲染位图时，按最终置入尺寸保持 **`300–600 dpi`** 物理分辨率（单独交付 PNG 检查稿或提交文件时 `>=600 dpi`）。
- **双栈配置模板与本地解释器入口**：编写 Python 或 R 定量绘图脚本前，读取 [Python 与 R 1:1 出版级绘图配置模板及本地解释器入口](references/plot-templates.md) 复用标准 `rcParams`（严禁混入 `DejaVu Sans` 回退）、`theme_pub_1to1()`、`PT_TO_MM` 换算及本地 Conda/Miniforge 解释器路径。

## 图形类别路由与绘图栈

根据目标视觉类型选用确定性可编辑的生产工具栈（**严禁调用 AI 位图生图子代理或扩散模型工具**生成科研数据图或机制示意图，因为光栅生图会丧失生物物理拓扑精度、单元素可编辑性与矢量清晰度）：

- **统计图表、生理波形、多组学与实拍生物图像面板** → 先读 [数据、多组学与实拍图像面板规范](references/data-and-omics-panels.md)、[高阶复合图谱与进阶包工作流](references/advanced-chart-archetypes.md) 与 [配色方案与视觉编码](references/color-palettes.md)，按目标媒介准确 1:1 物理尺寸由代码直接绘制定量图件，或对真实实验原图执行保真裁切、锁定色阶、内嵌标尺与多面板拼版：
  - *优先选用 R 栈*（`ggplot2` / `patchwork` / `ggdist` / `ggalluvial` / `ComplexUpset` / `forestploter` / `rms` / `ComplexHeatmap` / `circlize` / `ggraph`）：处理云雨分布与效应量估计、队列冲积流向图、表图一体临床森林图、限制性立方样条（RCS）叠加暴露密度底图、环形弦图、半矩阵关联网络与多层注释热图。
  - *优先选用 Python 栈*（`Matplotlib` / `Seaborn` / `Marsilea` + `legendkit` / `pyCirclize` / `UpSetPlot` / `Scanpy`）：处理高采样率电生理与血流动力学波形及相环图、原生 `AnnData` 单细胞与空间转录组面板、声明式多轨组合矩阵，以及同 CT / MRI 三维渲染或 `<svg>` 机制图混排的复合母图。
- **三维网格、形变场、CT / MRI 影像与器官—信号融合图** → 先读 [空间力学与三维可视化](references/spatial-mechanics.md)。严格跨状态锁定相机视角、投影与色标上下限；将高 DPI 三维/影像渲染图与矢量坐标轴、色标及匹配媒介的字号标签组合输出。
- **机制示意图、信号通路、因果图（DAG）与研究流程图** → 动笔绘制前务必先读 [机制示意图与拼图规范](references/schematics-and-assembly.md)：
  - *计算流程、数学几何、因果 DAG、CONSORT 流程图或干预时序线*：在严谨排版网格上使用结构化矢量代码（TikZ / Typst / 洁净 SVG + 真实数据缩略插图）构建。
  - *细胞、组织、器官与分子机制示意图*：由主作者直接编写**语义分组清晰、坐标可确定控制、单元素可独立编辑的矢量 `<svg>` 插图**，以柔和协调的同色系层次填充搭配更深一阶同色系描边（严禁廉价的 `#000000` 卡通粗黑框）。**按科学解释需要精确拿捏图元精细度**：信号传导布线、反馈回路与系统生理框图优先使用平涂色块与简练几何图形；仅当细胞/组织形态、细胞膜曲率或屏障微结构本身承担科学论点时，再有选择地引入有机三次贝塞尔轮廓、标准受体/离子通道/细胞器 `<defs>`/`<g>` 图元、克制渐变或 2–3 层内部景深（可按需集成经过字号与线宽统一规范化的 BioIcons / SciDraw / Servier / 项目自有 SVG 组件）。图内文字保持精简（`1–4` 个英文词）且通篇采用**统一的 Regular 深色字重**，避免 AI 生成风格的“粗体主标题 + 细浅副标题”双行堆砌及括号小字注解；绝不用粗糙无样式的 `Circle`/`FancyBboxPatch` 拼贴充当生物学结构，也不用塞满长句子的 `draw.io` / Mermaid 方框凑图。

## 核验与交付闭环

1. **先核实数据溯源，再跑确定性静态门禁**：检查精确表连接、计量单位、分母、独立生物学样本量 `n` 与技术重复区分及缺失值处理；导出 PDF/SVG 后先运行 [lint_figure.py](scripts/lint_figure.py)（默认 `--mode manuscript`，幻灯片传 `--mode slide`）。按已确定的载体要求使用 `--allow-cjk`、可重复的 `--allow-font FAMILY`、`--max-width-mm`、`--max-height-mm` 与 `--min-dpi` 覆盖默认样式；不要为了通过而放宽真实要求。脚本检查声明物理尺寸、PDF 嵌字、部分字体/文字规则与位图实际分辨率；SVG 的 `<text>`/`<path>` 只能提示编辑性，不能证明所有文字可编辑。CSS 布局、嵌套视口、`<use>` 实例或缺失工具等未覆盖项按输出标明未核，静态通过不代表科学关系、可读性或期刊要求全部通过。
2. **按载体分级目视复核，严禁陷入像素微调死循环**：
   - **独立投稿图 / 基金主图（新建或实质重设计）**：导出后用宿主图像查看工具目视检查 1 次实际成品（对照 [图件审核门禁](references/figure-review.md) 核查清晰度、独立 `A, B, C` 分图编号对齐、文字无重叠或裁切、单轴单一物理单位与图例对应）；发现硬伤集中一次性修完即可交付，**至多复查 1 次**，严禁“看图 → 微调 2px → 重导 → 再看图”反复循环。
   - **幻灯片配套示意图 / 批量局部微调**：跑通 `lint_figure.py --mode slide` 且确认导出文件已更新即可直接交付给用户目视检查；仅在明确修复具体重叠/裁切缺陷时针对该单图抽看 1 次确认，不再对多张幻灯片附图逐张渲染自检。
3. **保持源资产洁净同步**：将可复现绘图脚本、可编辑矢量母版文件与规定导出成品一并保存。仅在维护或测试 `scientific-visualization` 本技能自身时才需读取 [技能自测规范](references/evaluation.md)。
