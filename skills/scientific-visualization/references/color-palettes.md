# 科研配色方案与视觉编码

整幅复合图选用克制、协调的配色体系，使焦点比较跃然纸上，背景与参考结构退居安静底层。画布背景保持纯白（`#FFFFFF`），主要文本采用深炭黑或纯黑（`#1E293B`、`#111827` 或 `#000000`）。

## 1. 分组类别色板

每个实验分组、干预方案或细胞谱系在全篇论文的所有图件与分图中绑定**同一固定颜色**，并在关键对比中辅以点型、线型或曲线端点直标加以强化（兼顾黑白印刷与色觉障碍可读性）。

- **Nature Publishing Group (NPG) 风格 4 组生物医学色板（2–4 组常规对照的默认首选）**：
  - 深蓝 `#3C5488`（主对照 / 基线组 / Sham）
  - 珊瑚红 `#E64B35`（主干预 / 损伤组 / 核心聚焦组）
  - 青绿 `#00A087`（第三条件 / 修复组 / 保护性分支）
  - 天蓝 `#4DBBD5`（第四条件 / 次要比较组）
  *（双组对比优先选用 `#3C5488` 对 `#E64B35`。）*
- **Okabe–Ito 色盲友好 6 组色板（多组时程曲线叠加与临床队列优先）**：
  - 蓝 `#0072B2`、朱红 `#D55E00`、蓝绿 `#009E73`、紫红 `#CC79A7`、浅天蓝 `#56B4E9`、橙黄 `#E69F00` *（确有纯基线/假手术对照组需要降权退后时，可配深灰 `#475569`）*。
- **高维多类别（`>6–8` 类，如单细胞图谱分群）**：按大谱系归拢色相家族（例如上皮系蓝色簇、内皮系青绿簇、髓系橙红簇、淋巴系紫色簇），或只将 `2–3` 个聚焦亚群以高饱和主色点亮，其余背景细胞群压低为 `#CBD5E1` / `#E2E8F0`，切忌平铺 20 种刺眼彩虹色。

## 2. 中性背景底色与结构辅色

非焦点解剖结构、参考基线、配对连线与分区底框统一采用低饱和中性灰，确保任何背景元素都不与前沿数据色彩抢夺视线：

- **浅区隔底填色（区室 / 时相底带）**：`#F8FAFC`、`#F1F5F9`（冷板岩灰）、`#FAF8F5`（暖米石色），或采用低对比主色的 `5–10%` 透明叠加。
- **结构轮廓、配对细线与零刻度参考线**：`#CBD5E1`（浅灰）至 `#94A3B8`（中度板岩灰，`0.4–0.6 pt`）。
- **坐标轴脊、刻度与主字体墨色**：`#1E293B` 或 `#000000`。

## 3. 定量连续场与热图色阶

严禁使用视觉失真的 `jet` 或彩虹色阶（rainbow）。一律采用感知均匀的科学色表；本机 Python 栈已安装 `cmcrameri`（`cmc.batlow`、`cmc.vik`）、R 栈已安装 `scico`（`scico::scale_fill_scico(palette = "batlow")` / `"vik"`），可直接原生调用：

| 编码物理量类型 | 首选色表 | 内置备选 | 硬性约束 |
| :--- | :--- | :--- | :--- |
| **非负单调递增幅度**（表达量、应变、细胞密度、概率） | `batlow` | `viridis` 或 `cividis` | 直接并排比较的分图必须锁定同一色标上下限；色条旁写明物理单位 |
| **围绕中性零点双向偏离的有符号差异**（`log2FC`、`Z-score`、`ΔZ`、流量残差） | `vik` | `RdBu_r` | 除非另有明确科学理由，否则将 `0` 严格锁定在中性过渡中心并采用对称区间 `[-M, +M]` |
| **周期性或循环相角**（心动周期、昼夜节律或细胞周期相位） | `twilight` | `twilight` | 首尾回环相位在色表两端自然连续衔接 |
| **缺失值或掩膜外区域** | 显式 `#E2E8F0` 灰块或留白缺口 | 显式中性灰 | 严禁将 `NA` 或无效掩膜像素渲染成数值 `0` 所对应的颜色 |

## 4. 跨分图编码一致性纪律

- **单图内严格遵守一对一映射。** 切忌在同一复合图的不同分图中将同一套“颜色 + 线型”组合分配给两个毫无关系的序列（例如在 A–E 分图用实线蓝代表 `Vehicle` 对照组，到 F 分图却用同款实线蓝代表 `Arterial inflow`）。一旦下游面板从“干预分组比较”切换为“解剖区室或流体通路比较”，务必启用视觉清晰区隔的新色系子集或配合直观线旁直标文字。
