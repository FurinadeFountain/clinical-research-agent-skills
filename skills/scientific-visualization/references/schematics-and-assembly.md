# 机制示意图、架构框图与复合拼图规范

适用于绘制生物学/生理学机制示意图、信号转导与力学生物学通路、计算或数学模型架构图、因果有向无环图（DAG）以及临床/实验流程设计图。

## 1. 严格区分两类机制示意图，杜绝三类经典失误

示意图制作失败多源于选错视觉语法：用 `draw.io` 式文字方框堆砌科学机制、用粗糙单几何图元敷衍细胞解剖形态，或把严谨生物学图表交给不可控的光栅生图工具。动笔前先按题材分流：

| 图件类别 | 典型题材 | 视觉呈现与工程路径 |
| :--- | :--- | :--- |
| **A 类：计算流程、数学结构、因果与方案图** | 计算模型架构、信号处理/图像重建流水线、数学流形几何、因果 DAG、CONSORT 受试者流程图、实验干预时序轴 | **纯代码驱动矢量排版**（TikZ / XeLaTeX、Typst 或结构化 SVG 嵌入 Matplotlib 真实矢量微缩数据图），严格对齐毫米坐标网格。 |
| **B 类：生物、生理与临床病理机制示意图** | 微血管内皮屏障、干细胞谱系修复分化、力学与代谢转导通路、免疫—肿瘤基质互作、心—肾血流动力学偶联、器官及细胞病理生理 | **语义分组可控可编辑矢量 `<svg>` 插图**：由主制作者以清晰的图层 ID 与确定坐标直接编写；依据解释需要选配平涂拓扑区室或分层有机解剖轮廓（可按需集成经过字号与线宽统一规范化的 BioIcons / SciDraw / Servier / 项目自有 SVG 组件）。 |

**两类图件共守的三条红线：**
1. **严禁使用 AI 位图生图子代理或扩散模型工具**生成机制示意图——光栅输出既牺牲生物物理拓扑精确性，也使后续单节点修订与矢量清晰度无从谈起。
2. **严禁以简陋几何色块冒充真实生物学结构**——切忌直接用原生 Matplotlib `Circle`、`Ellipse`、`FancyBboxPatch`、生硬多边形或 `#000000` 粗黑线描边卡通块代替细胞、通道蛋白或脏器。
3. **严禁把生物医学机制画成塞满长句的 `draw.io` 或 Mermaid 文字流程图**。

## 2. B 类图件规范：可控矢量结构与按需拿捏的绘图精细度

每幅生物学机制图均直接编写为结构规整、按当前交付媒介标定尺寸、语义分组明确（`bg`、`anatomy`、`histology`、`overlays`、`labels` 或按功能命名的模块 `<g>` 组）的权威 `<svg>` 母版，遵守以下五项结构标准：

1. **在开放 `#FFFFFF` 画布上建立多尺度空间构图（或匹配幻灯片背景，零外框卡片）**
   - 将每个生物学过程锚定在真实解剖/亚细胞区室中，靠空间相对位置自然交代因果与输运方向，省去长句方框——例如：*血管腔与流体切应力 → 内皮糖萼与细胞间紧密连接 → 基底膜与周细胞间质 → 实质细胞微环境*，或 *细胞外基质刚度 → 细胞膜黏着斑与机械通道 → 细胞骨架 → 细胞核 YAP–TAZ 入核*。
   - 涉及组织级物理刺激联动胞内信号时，可在外围搭配**无框边缘状态小窗**（如 *Laminar flow*、*Disturbed shear*、*Stiffened matrix*），通过平滑三次贝塞尔过渡线连向**中央放大的细胞/组织屏障剖面图**；比较匹配实验条件（如 *Intact junction* 对 *Paracellular leak*）时，在同一解剖坐标系下左右或上下并列展示结构对照。
2. **确定可控的矢量图元与切合解释目标的渲染景深**
   - 保持每个 `<path>` 与 `<g>` 元素坐标明确、彼此独立可编辑，填充色调协调配合**更深一阶同色系描边**（亮度降低约 `20–35%`；组织与细胞器轮廓**绝不使用 `#000000` 纯黑边框**），确保在代码、Adobe Illustrator 或 BioRender 中均易单独微调。
   - **按科学解释职责精准匹配绘制复杂度**，避免为每张图强行堆砌过度装饰：
     - *信号接线、负反馈环路、系统生理偶联或汇报概览图*：优先选用**洁净平涂色块与简练几何/平滑曲线轮廓**，让通路拓扑一目了然。
     - *细胞形态重构、褶皱质膜、血管—上皮屏障或组织显微剖面*：采用平滑闭合**三次贝塞尔轮廓（`C` / `S` 指令）**，并在组织形态真正承载科学信息时适度引入**克制的 `<linearGradient>` / `<radialGradient>` 或 2–3 层内部景深**（例如双凹红细胞高光、核膜亮缘、间质胶原纹理、糖萼刷状层）。底层解剖背景统一去饱和度降低权重，让 `2–3` 种焦点信号色自然凸显。
3. **建立标准亚细胞与分子 `<defs>` / `<g>` 复用图元**
   - 当分子构象或细胞器身份本身具有识别意义时，编写可复用的生物学图元符号库替代单调圆点：
     - **细胞膜与跨膜受体/通道**：褶皱质膜在跨膜蛋白两侧局部点缀**磷脂双分子层亲水头部与疏水尾链短刻度**；多次跨膜蛇形 GPCR 桶状受体配对契合球形配体（如 thrombin–PAR2）；对称双体成孔离子通道（`TRPV4`）配透膜离子流；相对细胞膜之间跨越分布的成对连接子斑块（`Cx43`）。
     - **细胞器与囊泡转运**：肾形/分叶状细胞核、折叠嵴线粒体、多层扁平囊状内质网钙库及释放钙离子，以及与质膜融合开口释放分泌颗粒的胞吐孔道。
   - 亦可将遵守开源协议的优质矢量库组件（**BioIcons**、**SciDraw**、**Servier Medical Art** CC-BY、**Reactome**）或课题组既有 BioRender/Illustrator 导出 SVG 统一归一化色板与描边后编入语义 `<g>` 分组。
4. **语义分支着色与依证据等级校准的箭头语法**
   - 为不同功能机制分支分配稳重协调的区分色（例如暖赭色表示上皮—连接传递、青蓝绿表示跨膜离子/GPCR 信号、赤陶红表示机械牵拉形变），并保持每种因果含义唯一绑定一种颜色与线型。
   - 在箭头图形上显式区分证据确认程度，并在**图底极简图例条**与图注中给出定义：
     - 实线箭头（`→`）：**已发表确认通路（Published pathway）**——已验证的激活、转化或物理通量。
     - 平头 T 形阻滞线（`⊣`）：抑制、阻断或下调。
     - 虚线箭头（`⇢`）：**待验证/假说连接（Proposed link）**——间接调控、多步级联或本研究拟检验的推论联系。
5. **按媒介标定 `<svg viewBox>`、统一单字重排印与“渲染—目检—微调”闭环**
   - 落笔前依照 [SKILL.md](../SKILL.md#媒介物理尺寸与字号预设) 中当前目标媒介的 1:1 物理尺寸固定 `<svg viewBox="...">`（对应论文栏宽、Beamer/PPTX 内容框或海报版框），预先划定互不侵占的构图分区再写路径坐标。
   - 图内文字严格维持稀疏精简（`1–4` 词名词或物理量短标，如 `Shear stress`、`Cytosolic Ca²⁺`、`Cx43`、`TNF-α release`），采用当前预设的 Regular 正文字号（论文预设 `6–7 pt` Regular Arial；化学上下标在 `<text xml:space="preserve">` 中配合 `<tspan>` 基线微调；必要时配 `0.4–0.5 pt` 极细灰引导线；完整叙述与队列样本量均放进正文图注）。
   - **统一 Regular 深墨排印（远离 AI 信息图套路）**：机制图内标签一律使用 **Regular 深炭黑（`#111827`）**，**Bold** 严格仅用于独立的分图字母（`A, B, C`）或极少数不可或缺的 1–2 个核心枢纽标签。严禁堆砌“彩色加粗大字 + 浅灰小字解释”交替标题块、五颜六色粗体词或图内括号解释小字。
   - **强制视觉验收闭环**：将 `.svg` 实际渲染为高分 PNG/PDF（通过 `rsvg-convert`、`resvg`、CairoSVG 或无头浏览器），直接用支持图像查看的工具目视检查渲染成品，逐点微调 `<path>` 贝塞尔控制点与 `<text>` 坐标，直到零文字压线、零生硬切角且无任何边缘裁切；同时保持分组图层与 ID 整洁，使该 `.svg` 母版可直接导入 Adobe Illustrator 或 BioRender 继续深加工。

## 3. A 类图件规范：计算流程、数学几何与实验路径图

- **毫米网格对齐与极细边线几何。** 在目标媒介的 1:1 物理宽度下（论文栏宽或幻灯片置入框）将全部节点锁定在规整行列坐标上。采用适配预设的极细边线（印刷稿 `0.5–0.75 pt`，幻灯片相应放大）、克制微圆角（印刷稿最大 `1.5–2.5 mm`）、`4–8%` 低饱和中性或主题填色，并留出充裕框内边距（文字距边框 `>=2 mm`）。
- **用真实数据矢量缩略图替代大段文字卡片。** 绘制算法或方法管线图时，将精简算子标签与规范数学符号（`Latin Modern Math`）搭配真实或确定性种子算出的矢量微缩数据切片——例如真实的电生理或血流动力学波形片段、三维解剖有限元网格、稀疏矩阵热图块、核密度分布曲线或流形轨迹缩略图。
- **实验干预时序轴与 CONSORT 入排流程图。** 实验流程采用带单位刻度的洁净水平时间轴（如 `30 min ischemia → 6 h reperfusion → Thrombin 0.5 U/mL`）；临床队列入排流程图采用严谨层级的计数与排除模块（清晰写明筛查总例数、实际入组数、逐条列明原因的排除例数以及最终纳入统计分析的 `n`）。

## 4. 多分图复合组装规范

- **先作行带式模块化整页物理规划。** 面对高水平期刊常见的 `6–12+` 子图复合整图，先在双栏整页物理坐标系（默认宽 `174–183 mm`，整高 `160–200 mm`；其他媒介见 [SKILL.md](../SKILL.md#媒介物理尺寸与字号预设)）上按叙事阶段划定 `3–4` 条横向行带或主次非对称区块，在构图网格中提前分配各模块每枚组件（`<svg>` 实验方案、高 `DPI` 显微 / CT / MRI 裁片、R `ggplot2`/`ComplexHeatmap` 统计组学图、Python `Matplotlib`/`Marsilea` 生理波形）的精确毫米边界框，并严格拉开跨叙事模块（`5–8 mm`）、同模块兄弟子图（`2.5–4 mm`）与同图边际轨（`0.8–2 mm`）的三级留白间距。
- **跨栈异构组件均按最终分配毫米宽高 1:1 原生生成。** 每枚 Python、R 与 `<svg>` 子图必须严格按照各自被分配到的终稿物理尺寸独立生成导出，确保十余个跨工具子图的 `6–7 pt` Regular 正文标注与 `0.6 pt` 轴线宽在整页视觉上完全一致，彻底杜绝生成大图后再硬性压缩拼接引发的字体畸变。
- **共享对齐基线与代码—矢量双层分离。** 通过精确拼版网格（`matplotlib.gridspec` / `subfigures`、`patchwork`、`cowplot::plot_grid` 或 SVG 整页总装脚本）严密对齐每行每列的外轴线，在总装层统一布置共享水平与垂直基准线的 `8 pt` Bold 分图编号（`A–L` 或 *Nature* 体例 `a–l`）以及模块化去重后的公共图例；为代码生成的定量数据图与外围矢量版面标注层保持独立稳定的文件名与 SVG `<g>` ID，使实测数据更新可无损重新导出面板而不覆盖精修矢量注释。
