# 交付前数据核验与 1:1 媒介视觉审核门禁

凡交付新建科研图件、实质性改版图件或受托开展图件审稿，均按以下适用条目检验。样式预设可由用户、项目或期刊明确要求覆盖，沿用 [入口中的参数与未核范围说明](../SKILL.md#核验与交付闭环)；科学与数据真实性约束不随样式改变。禁止仅凭代码逻辑或坐标推算替视觉效果背书，务必直接通过宿主支持图像查看的工具打开实际渲染导出的图像或 PDF 页面目视验收。

## 1. 科学与数据保真度门禁（在源码与数据中核实）

- **对比设计与统计单元准确**：图上展示的实验分组、观察时间窗、基线、分母与样本量 `n` 须与原始数据和研究设计完全一致；严格区分独立生物学重复与嵌套技术重复。
- **键值对齐与缺失值区隔**：多面板热图、顶部注释条与配对连线须采用经验证的唯一主键连接与统一规范排序；显式区分缺失值 `NA`/掩膜区域与实测零值 `0`。
- **计量单位与显示变换透明**：每条坐标轴和色条须标明准确的物理或统计单位（如 `mmHg`、`L/min`、`µM`、`log2FC`）；单轴严格对应单一物理单位；若三维形变采用放大倍率（`alpha != 1`），同一对比系列须锁定相同倍率并显式披露。
- **因果强度与体系边界诚实**：机制通路箭头清晰区分已发表实证与待检假说；绝不将来自不同物种、细胞模型或互不兼容时程的结果直接接成同一条未加分隔的连续通路。

## 2. 1:1 目标媒介视觉否决门禁（目视检查实际导出成品）

按最终投放媒介的真实预设尺度审视导出的 PDF/PNG（印刷论文正文 `6–7 pt`；Beamer 幻灯片 `8–10 pt`；PPTX/Keynote `14–18 pt`），一旦出现以下任一硬伤，修复后方可交付：

1. **多子图叙事布局、分图编号与冗余标题缺陷（论文预设）**：
   - 分图字母后附加叙述性小标题（如 `A  Arterial pressure`、`B  Volcano plot` 或泛化的 `ax.set_title(...)`）→ **删除子图标题，仅保留对齐于共同行列基准线的独立 `8 pt` Bold `A–L`**（或依期刊体例用 `a–l`）。
   - `6–12+` 子图复合整图的分图编号出现跳行跳跃或失去叙事模块分组（全图被机械均分为单调等宽方格、缺乏“跨模块 > 同模块”留白层级差，或同一模块内的相同分组图例在相邻子图中反复铺陈占位）→ **按 [排版设计与标注偏好](design-preferences.md) 重整为“场景切入 → 定性锚点 → 定量验证 → 机制扰动”行带式 Z 字动线，建立主次锚点并集中合并公共图例**。
   - 单面板独立图误加多余的 `A` 编号，或论文图件画布内出现未要求的总标题、副标题、工艺横幅或右下角防御性免责小字 → **直接删除**。
2. **文字碰撞、裁切、不可读或 AI 信息图式排版痕迹**：
   - 坐标轴标签、刻度值、色条标题、显著性括号、误差棒或图例与柱体、曲线或邻近面板发生重叠遮挡（如 `twinx` 右轴标签撞上柱条，或画布边缘字母下延部分被裁切）→ **调整面板间距与页边距后重新导出**。
   - 正文标注低于当前媒介下限（印刷 `<5 pt`、Beamer `<7 pt`、PPTX `<12 pt`）、轴标题过粗过大，或因事后强行缩放单个子图导致各面板实际字号大小不一 → **按准确 1:1 目标尺寸重新生图**。
   - **AI 信息图式堆砌杂音**：文字注释过密、交替出现“彩色粗体标题 + 细浅副标题”的双行堆叠、五颜六色加粗标签或机制图内部塞满括号注解小字 → **剥离解释性副行与注解，图内标注统一收束为 Regular `#111827` 深墨色**。
3. **图表与视觉编码反模式**：
   - 不同物理单位混画在同一个 `Value` 纵轴上 → **拆分为独立物理坐标轴或分面**。
   - 中小样本连续型生物学数据仅用光秃秃的“炸药包柱状图”表达 → **叠加独立生物学重复散点或配对轨迹线**；同一观测环节内部的多维耦合关系被拆碎成一排低信息量单调基础方格 → **对照 [高阶复合图谱与进阶包工作流](advanced-chart-archetypes.md) 合并为云雨、RCS 耦合、表图森林图或跨轨道矩阵**（而承载全图不同证据递进环节的面板应保持独立 `A–L` 分图叙事推进）。
   - **装饰性炫技与概率分布越界**：采用三维柱饼、伪透视倾斜、无周期依据的极坐标环形拉伸，或核密度图未设物理下界截断导致概率曲线跨越 `0` 线伸入负值区 → **切换回精准二维正交投影并启用 `trim = TRUE` / `cut = 0` 边界截断**。
   - **R/Python 跨语言字号、回退字体与矢量嵌字失真**：`geom_text()` 未做 `25.4 / 72.27` 毫米换算造成标签偏大偏粗，或导出 PDF/SVG 触发 Type 3 字体、轮廓化路径文本、未经指定的字体回退或语言混入 → 按本次媒介要求应用 [plot-templates.md](plot-templates.md) 预设和必要覆盖参数，运行 [lint_figure.py](../scripts/lint_figure.py)，修复实际问题并如实记录未核项，不以消除所有告警为验收目标。
   - 同一复合图内部将相同颜色配相同线型重复指代两种毫无关系的序列、残留无用上右边框线或出现干扰读数的密密麻麻背景网格 → **清理重编**。
   - **实拍显微/病理与印迹缺陷**：实拍图像缺失带物理尺寸的图内比例尺、高倍 `Inset` 未在低倍全景准确框定 `ROI` 来源、多通道荧光直接红绿叠加且未拆出单通道灰度图，或组间对比未锁定 `LUT` 显示强度范围 → **补齐比例尺与 `ROI` 定位框、切换色盲安全通道并拆分单通道灰度图、统一组间显示动态范围**。
4. **机制示意图工艺达标核查**：
   - 采用 AI 光栅生图、粗糙几何色块充当细胞器官（`Circle`/`FancyBboxPatch` 配 `#000000` 粗黑框）或塞满句子的 `draw.io`/Mermaid 框图 → **按 [机制示意图与拼图规范](schematics-and-assembly.md) 重构为语义分组清晰、可控可编辑的矢量 `<svg>`**；核查视觉复杂度是否切合科学目标（信号接线用洁净平涂形状，组织屏障形态用有机三次贝塞尔区室与克制景深）、深一阶同色系描边是否协调、箭头是否区分证据层级（`Published pathway` 对 `Proposed link`）、`1–4` 词 Regular 名词标注是否精炼无碰撞。
5. **输出规范与 Notion 交付完整性**：
   - 确认 PDF/SVG 内文本保持可检索可编辑矢量对象（`pdf.fonttype = 42`、`svg.fonttype = 'none'`），且内嵌位图按最终置入尺寸达到 `300–600 dpi`。
   - 写入或更新 Notion 页面中的图件时，核查图题与图注是否已完整写入图片块原生图注字段（含有效来源链接与提及），并清理图片下方重复粘贴的正文段落。

## 3. 有界协作与局部改动复核范围

- **唯一权威制图者**：由一位主制作者统筹源图文件与修改集成。执行科学含义不变的局部微调时，仅复核改动元素、紧邻留白间距与重导出成品即可。
- **何时启用独立审图者**：仅在制作高度复杂的多面板/多源复合新图，或反复遗漏视觉规范时，才加派**一位**只读审图代理，向其提供渲染成品、目标栏宽与源文件路径（若当时已按流程运行 `academic-reviewer` 正式交付物审计，则直接复用该审查通道，不重复派单）。依据回报集中修完实质缺陷后即行收手。
