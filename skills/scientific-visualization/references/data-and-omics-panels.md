# 统计、生理波形、多组学与实拍生物图像面板规范

适用于绘制实验统计图、临床队列图、电生理与血流动力学波形、单细胞与空间多组学图件，以及显微荧光、组织病理、电镜与免疫印迹实拍面板。上色和排版前，务必先在代码层面核实并绑定生物学物理量、单位以及真实统计重复单元；涉及多维分布、轨迹流转、亚组异质性或跨模态关联的高阶形态选型，配合 [高阶复合图谱与进阶包工作流](advanced-chart-archetypes.md) 使用。

## 1. 实验与临床统计面板

- **严守生物学重复与技术重复界限。** 清晰区分独立生物学样本单元（患者、实验动物、独立供体）与嵌套观测单元（单个细胞、空间点、显微视野、细胞培养孔、连续心动周期或采样帧）。合理按嵌套结构聚合或构建混合效应模型，基于生物学重复层级计算置信区间/离散度，并在图注中同时写明样本量 `n` 及对应的统计单位。
- **展示完整数据分布与高阶效应结构，摒弃孤零零的“炸药包柱状图”。**
  - 当连续型变量的生物学样本量处于中小规模（`n <= 30`）时，将**每一个独立生物学样本的散点**叠加在简洁的汇总图形上（抖动散点/蜂群图 + 均值或中位线及 SD / IQR / 95% CI，或箱线叠散点）；样本充足时升级为**云雨图（Raincloud：`ggdist` / `gghalves`）**、**脊线分布图（`ggridges`）**或**双面板均值差估计图（Gardner–Altman / Cumming 面板）**，同时完整呈现密度曲线、分位数区间与样本点。
  - 涉及配对或自身前后/多条件重复测量设计时（例如同一受试者或同一离体灌注标本先后对比 `Baseline` vs. `Stimulation` vs. `Washout`，或干预前后对照），用细浅的**配对连接轨迹线（`0.5 pt`，`alpha=0.35–0.5`）**串连配对单元并叠合组间汇总。
  - 展示临床队列分型随病程转归、治疗线数切换或多重特征交集（`>= 4` 组）时，优先选用**冲积流向图（`ggalluvial`）**或**UpSet 交集联动矩阵（`ComplexUpset` / `upsetplot` / `Marsilea`）**替代并列堆叠柱状图或复杂韦恩图。
  - 检验连续暴露指标的非线性效应时，选用**限制性立方样条（RCS：`rms` + `ggplot2` / `patchwork`）曲线同轴耦合下方暴露分布直方图/地毯图**，完整交代效应区间与尾部样本稀疏区。
  - 纯粹柱状图仅限用于绝对计数、事件发生率或构成比例（`%`，总和为 `100%`），且纵轴起点必须严格锚定于 `0`。
- **单轴严格单一物理单位准则。** 严禁把物理单位不同的变量（例如心输出量 `L/min` 与动脉血压 `mmHg`）塞在同一个笼统的 `Value` 纵轴上对比。每种物理量均独立成子图或分面，使用 `Physical quantity (unit)` 形式清晰标注纵轴（如 `MAP (mmHg)`、`LV CO (L/min)`）。
- **规避易发生遮挡碰撞的双 Y 轴。** 宁可采用共享同步时间 X 轴的纵向堆叠分图，或并列分面，也不轻易使用左右双纵轴（`twinx`），避免曲线与柱体交错遮挡或人为造成尺度错觉。
- **凸显效应量与区间估计，避免唯 P 值星号化。** 优先使用**表图一体对齐森林图（`forestploter` / `patchwork`）**或均值差估计面板集中呈现样本数、事件率、点估计、置信区间与亚组交互 `P` 值；确需在分布图上添加组间显著性括号时，使用精细水平连线（`0.5 pt`，`6 pt` 精确 `P` 值或校准星号标注）并在最高数据点上方留出充裕净空。

## 2. 生理波形、环图与临床时间序列

- **时间轴严密对齐的纵向波形堆叠。** 绘制血流动力学或电生理多导联波形（如 `ECG`、`Arterial pressure`、`Flow`、`LV volume`、`LFP`）时，采用**锁定同一时间轴上下限**的垂直堆叠面板；隐藏中间多余的 X 轴刻度标签，仅在最底层波形下方保留完整的时间横轴 `Time (s)`；涉及多周期或多动物汇聚对比时，绘制周期相位归一化后的**中位轨迹实线配第 25–75 百分位（IQR）半透明离散带**以展示分布变异（若旨在呈现中位数或均值估计的不确定性，则按独立生物学样本层级计算并绘制 `95% CI` 置信带，在图注中写明区间口径），并在关键给药或刺激窗口加配局部时间放大插图或联动对应的 CT / MRI 空间时相切片。
- **规范物理单位与生理零线。** 正确排印化学式及物理量上下标（如 `Ca$^{2+}$`、`mL/min`、`mmHg`）。对生理零位线（如 `Flow = 0 mL/s`、`ΔV = 0`）使用细浅的中性灰虚线（`0.5 pt`，`#94A3B8`）标出；当收缩/舒张或刺激/静息时相切换直接支撑论点时（如短暂血管阻断或光遗传学刺激窗），可加铺 `6–8%` 低饱和竖向时相底带加以提示。
- **压力—容积环（P–V loop）与相环图。** 保持恰当纵横比例；当心室充盈—射血或粘弹性滞回（hysteresis）方向具有力学意义时，在环线上顺势加入小巧的方向箭头；直接在曲线关键拐点或顺应性/弹性斜率旁近距离标注，减少视线往返于遥远图例框的负担。
- **全图维持 1 对 1 唯一图例身份。** 同一复合图内部不得将完全相同的“颜色 + 线型”分配给两个不同变量或实验条件。把无框紧凑图例贴近其解释的面板群放置，或在多条曲线末端直接加注标签。

## 3. 单细胞、多组学与空间转录组面板

- **在代码中先行锁定规范实体排序。** 绘图前先为样本、细胞类型、特征基因与实验条件确立唯一权威序列，再将每一张热图、气泡图、边际条形图及顶部注释条全部按该主键重排对齐。以程序代码核实矩阵维度、重复行/列名及真零值与缺失值边界（缺失值显式留空或填中性灰并加注说明，严禁默默把 `NA` 转成 `0`）。
- **边际组合联动与高阶互作图谱（`Marsilea` / `ComplexHeatmap` / `circlize` 范式）。**
  - 利用声明式多轨矩阵把细胞亚群比例、样本临床表型注释带、通路富集森林/柱条或拟时序平滑动力学带严密对齐主热图四边；仅当边际统计回答独立生物学问题时才增设对应轨道（例如将单细胞平均表达量上升同细胞亚群丰度扩增区分开来）。
  - 表达细胞—细胞配体—受体通讯权重或跨器官模态偶联时，采用降噪过滤后的**弦图（`circlize` / `pycirclize`）**或**半三角特征相关矩阵耦合外部临床表型贝塞尔网络弧**，在同一张复合面板中交待组内共线性与跨组外在关联；同细胞类型内不同干预条件对比可采用对拼**劈半小提琴图（Split violin）**。
- **气泡图（Dot plot）与热图双编码标注。** 同时以点面积映射表达细胞占比、以颜色映射平均/标准化表达量时，必须为**两种视觉通道**均配齐清晰带单位的图例（如 `% expressed` 与 `Mean log1p expr.` 或 `Z-score`）。非负表达强度采用感知连续色表，正负对数倍变或标准化得分采用严格零中心对称的发散色表（参见 [配色方案与视觉编码](color-palettes.md)）。
- **降维嵌入、拟时序轨迹与空间组织视野（`Squidpy` / `CellRank` 范式）。**
  - 锁定 UMAP / t-SNE / 空间转录组坐标的 `1:1` 等比例纵横比；省略无物理意义的 UMAP 坐标数字刻度（改为左下角精简的直角双箭头 `UMAP1` / `UMAP2` 指示），同时在 H&E、免疫荧光或 Visium 组织切片图上务必保留真实物理比例尺（`µm` 或 `mm`）。
  - 全切片概览图与带清晰定位方框的高倍感兴趣区（ROI）成对呈现；同一细胞类型的配色在 UMAP、空间切片图、比例堆叠条与拟时序轨迹之间保持绝对一致。
  - 严格将计算推断的 `Pseudotime` 与真实实验经过时间（elapsed time）区分标注；在图面与表达层级中同样保持空间共定位或配体—受体富集分数同经功能验证的因果信号通路之间的界限。

## 4. 显微成像、组织病理与印迹实拍面板

- **多通道荧光色盲安全与单通道灰度拆分**：双通道叠加优先选用色盲安全组合（`Magenta + Green` 或 `Cyan + Magenta`），规避红绿直接合并；`>= 3` 通道或需展示精细荧光强度梯度时，在合并图旁并列展示关键单通道的灰度或反相灰度图（Inverted grayscale），确保暗弱信号细节清晰可辨。
- **跨尺度局部放大框（`Inset`）与图内比例尺**：使用高倍插图呈现局部或亚细胞结构时，在低倍全景图上以高对比度方框精确标出对应 `ROI` 位置；所有显微、病理、电镜及大体标本实拍图均在图内高对比衬底处直接放置标明物理尺寸（如 `50 µm`、`1 mm`）的比例尺，图注补充物种、组织与染色/抗体信息。
- **组间显示动态范围锁定与适度标注**：参与组间定性或半定量对比的实拍图严格锁定同一采集曝光与显示查找表（`LUT`）强度上下限；图内箭头、星号或分界线采用色盲可辨的形状与明度对比，保持目标结构不被过度遮挡。
- **免疫印迹（Western blot）与凝胶条带保真**：紧邻条带标明分子量标志物（`kDa`）及对应内参通道，如实标示裁切边界与同胶/分胶关系，保持自然背景灰度与完整信号动态范围。
