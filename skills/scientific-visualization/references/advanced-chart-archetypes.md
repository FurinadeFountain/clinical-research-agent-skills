# 高阶复合图谱与进阶包工作流

适用于新建数据图件、实质性版面重设计以及多维关系图表升级。当**同一观测或论证环节内部**同时包含分布形态、个体轨迹、效应不确定性、多亚组对比或跨模态关联时，在单一分图编号内采用高信息密度的分层复合视觉语法；而当整幅全图需要串联研究切入、表型锚点、定量证实与机制扰动等多个叙事环节时，配合 [排版设计与标注偏好](design-preferences.md) 统筹组织为层次分明的 `6–12+` 子图完整结果故事版面。

## 1. 图形升维的核心准则与审美边界

- **在单个证据单元层面先做视觉升维评估。** 面对同一环节内存在 `>= 3` 个耦合变量、嵌套分组结构、非线性剂量效应或跨模态联动数据时，优先评估如何收束进一个高密度的复合面板：将“完整分布 + 个体/配对变化 + 效应量置信区间”集成在同一视角下，用边际联动轨道把临床亚表型注释、统计量或富集条直接锁进主矩阵，并以主次面积比例突出核心发现面板，避免将同一个多维观测强行拆成一排平庸的单一箱线图或柱状方格。
- **以信息架构创新界定审美边界。** 顶级医学与综合期刊（*Nature*、*Nature Medicine*、*NEJM*、*AJRCCM*）的高级感源于高密度的多维定量编码、克制的色彩层级、主次分明的版面比例以及严密对齐的跨轨道坐标轴。
- **严禁以表面装饰替代科学可读性。** 严格排除三维柱状图、三维饼图、伪透视倾斜平面、将非周期线性变量强行弯成极坐标环图、未校准双 Y 轴，以及阴影、发光或强渐变等干扰几何长度和颜色定量读数的视觉噪点。

## 2. 从常规图到顶刊高阶图谱的选型矩阵

| 数据关系与论证场景 | 应升级替换的常规画法 | 顶刊高阶图形范式 | 关键视觉分层要素 | 首选 R / Python 包生态 |
| :--- | :--- | :--- | :--- | :--- |
| **连续变量分布与效应量估计** | 普通箱线图或小提琴图配顶部星号 | **云雨图（Raincloud）**或 **Gardner–Altman / Cumming 差值估计面板** | 半侧核密度峰 + 极简四分位细条与中位点 + 对侧独立样本蜂群散点（或配对斜率轨迹线）；联动侧边或下侧面板展示自举（bootstrap）均值差分布及 `95% CI` | **R**：`ggdist`、`gghalves`、`ggbeeswarm`、`patchwork`；**Python**：`scipy.stats.bootstrap` + `seaborn` / `matplotlib` 联动子轴 |
| **队列分型流转与临床干预路径** | 多时点并列堆叠柱状图 | **冲积流向图（Alluvial / Sankey）** | 各时点节点柱高严格映射真实患者占比并直标 `n (%)`，流带设置 `0.35–0.55` 透明度，通过核心色高亮关键恶化或缓解迁移支 | **R**：`ggalluvial`；**Python**：`pyCirclize` 或 `matplotlib.path` 定制三次贝塞尔流带 |
| **高维特征或队列集合交集（`>= 4` 组）** | 多重交叠椭圆韦恩图 | **UpSet 交集点阵联动边际特征轨** | 底部点线连接矩阵按交集规模或阶数排序，上方柱体标出交集精确计数，顶部或侧边同步对齐展示对应交集亚群的临床结局或表达分布 | **R**：`ComplexUpset`、`ComplexHeatmap::UpSet`；**Python**：`upsetplot`、`marsilea.UpSet` |
| **多亚组异质性、多因素回归与敏感性分析** | 孤立误差棒图配分离正文表 | **表图一体对齐森林图（Aligned Table-Forest Plot）** | 左侧按临床层级缩进对齐亚组名称与 `Events / Total (%)` 文本列；中央效应轴设零效应参考虚线并用方块面积映射权重；右侧对齐 `HR/OR (95% CI)` 与 `P for interaction`，奇偶行铺极浅 `#F8FAFC` 底带防串行 | **R**：`forestploter`、`patchwork`；**Python**：`marsilea` 文本轨与森林轨对齐拼装 |
| **连续暴露与临床或生理结局的非线性关系** | 按分位数生硬切割的柱状图 | **限制性立方样条（RCS）效应曲线同轴耦合暴露分布底图** | 上方主面板绘平滑点估计曲线与 `15–20%` 透明 `95% CI` 置信带，标出参考拐点及 `P_overall` / `P_nonlinear`；下方共享 X 轴紧贴暴露直方图、核密度脊或地毯刻度（rug），直观揭示样本尾部稀疏区 | **R**：`rms` + `ggplot2` + `patchwork`；**Python**：`patsy.cr` + `statsmodels` + `gridspec`（上下高度比约 `4:1`） |
| **跨模态关联、配体—受体通讯与多组学整合** | 大块对称红蓝相关方阵或密集杂乱网络球 | **(a) 半矩阵相关热图耦合外部临床表型贝塞尔网络弧**；**(b) 弦图（Chord / Circos）**；**(c) 跨轨道声明式复合画布** | (a) 上/下三角热图编码组内共线性，外侧连线线宽与色阶映射临床变量 Mantel/相关强度及显著性；(b) 环形弦图编码细胞通讯通量或器官偶联；(c) 主矩阵严密锁齐临床注释色带、通路森林/柱条与拟时序平滑动力学带 | **R**：`ComplexHeatmap`、`circlize`、`ggraph` + `tidygraph`、`aplot`；**Python**：`marsilea` + `legendkit`、`pycirclize`、`adjustText` |

## 3. 高阶图型实现与跨语言拼版防错要点

### 3.1 云雨图与脊线密度图的边界与错位控制

- **将核密度估计严格截断在物理可行域内。** 对于荧光强度、细胞计数、表达量等非负或实测有界指标，务必开启密度边界截断（R 中 `ggdist::stat_halfeye` 或 `geom_density(trim = TRUE)`，Python Seaborn 中 `cut=0`），杜绝平滑核曲线越过 `0` 线伸入无意义负值区。
- **让核密度、汇总统计条与散点各自错峰排布。** 使用 `ggdist::stat_halfeye` 时配合负侧偏移与正负向不对称区间，或用 `gghalves::geom_half_violin` 配对侧 `ggbeeswarm::geom_beeswarm`；在 Python 中将半提琴裁剪至中心线一侧，散点与均值/IQR 误差条置于另一侧，防止散点压住轮廓峰顶。

### 3.2 冲积流向图、UpSet 矩阵与表图森林图对齐

- **冲积图保持守恒流宽与清晰直标。** 在 `ggalluvial` 中确保每个纵列堆叠总和精确等于队列基线样本量（若含随访失访或死亡结局，单独设为显式终末节点而不得凭空截断），把 `n` 与百分比直接标于足够宽阔的色柱内，窄带用引线外标并启用 `ggrepel`。
- **表图一体森林图统一数值格式与行距。** 借助 `forestploter::forest()` 或 `patchwork` 拼接无边框 `ggplot2` 文本轨时，固定等宽对齐或固定小数位数（如 `1.24 (0.98–1.56)`），在交互项列和异质性标题上保留足量右侧净空，并用浅灰水平分隔线与缩进直观表达分层主次。
- **UpSet 矩阵筛选有生物学意义的交集。** 当集合数超过 `5` 个导致全组合数膨胀时，按交集元素数量降序仅保留核心交集或设置最小交集阈值（如 `min_size`），并在边际面板附带各交集对应的生理/预后变量箱线分布，避免空留一排计数柱。

### 3.3 弦图、半矩阵网络与跨轨道复合画布

- **弦图（`circlize` / `pycirclize`）严格控噪。** 将环形扇区控制在 `<= 12` 个主要谱系或器官区室；按强度阈值或显著性过滤次要配体—受体对，低权重背景弧压为 `#E2E8F0`（高透明）并让重点机制通路最后绘制于最上层；开启扇区文字径向自动翻转（`facing = "clockwise"` 配合 `niceFacing = TRUE`），外环可按需加配细胞丰度比例刻度环。
- **半矩阵关联热图与外部临床网络（类 `linkET` 范式）防止弦线交叉穿越主矩阵。** 只渲染上三角或下三角相关矩阵并隐藏对角线冗余格子，将临床结局节点沿三角斜边外侧均匀阶梯排布；连线采用柔和贝塞尔曲线向外侧或斜对角张开，以虚实/色阶编码显著性层级，以线宽编码相关系数或统计量绝对值，并附清晰独立的线宽与颜色双重图例。
- **跨轨道热图（`ComplexHeatmap` / `Marsilea`）锁定主键与紧凑轨距。** 先在共享索引表核对样本或基因唯一主键，将轨道间隙收紧在 `1–2.5 mm`；相邻分面只保留外侧坐标标签，避免重复列名挤占版面；在 Python `Marsilea` 中牢记 `width` 与 `height` 参数以**英寸**计（传入 `目标毫米 * MM`），并通过 `cbar_kws` / `legend_kws` 指定 `title_fontsize = 6.5`、`fontsize = 6.0` 与充足 `add_legends(pad = ...)` 留白，防止图例撞入右侧边际柱图。使用 `ComplexHeatmap::packLegend()` 或 `legendkit` 将连续色条与离散注释图例集中排布在统一侧边。

### 3.4 R 与 Python 跨语言排印及矢量导出一致性

- **区分 `ggplot2` 主题字号与几何图层文字单位。** `theme()` 中的 `size` 参数单位为 **pt**，而 `geom_text()`、`geom_label()` 与 `annotate("text", ...)` 中的 `size` 单位为 **mm**，须统一换算：`PT_TO_MM <- 25.4 / 72.27`（例如印刷预设 `6 pt` 写作 `size = 6 * PT_TO_MM`，细线宽 `0.6 pt` 写作 `linewidth = 0.6 * PT_TO_MM`）。
- **选用可嵌入真字体的 R 矢量导出设备。** 导出 SVG 使用 `svglite::svglite(..., system_fonts = list(sans = "Arial"))`；在 macOS 上导出矢量 PDF 优先使用原生 `grDevices::quartz(type = "pdf", family = "Arial")`（实测无 conda Cairo 的 Type 3 字体回退），非 macOS 环境退用 `cairo_pdf(..., family = "Arial")` 并用 `check_pdf_fonts.py` 核验嵌入式 TrueType 字体，保证 R 生成子图与 Python `Matplotlib`（`pdf.fonttype = 42`）在 Illustrator 或拼版脚本中无缝统一。
