# 技能维护与行为评测规范

仅在维护或测试 `scientific-visualization` 本技能自身时读取；日常制作或修改科研图件无需加载。

1. **检验可观测产物，而不是只盯提示词字面。** 调整本技能的编排逻辑或核心规范后，应在隔离复制的真实任务样本上开展端到端验证：
   - **高阶复合定量与跨栈图件**：在 Python（`Matplotlib` / `Marsilea` / `pyCirclize`）与 R（`ggplot2` / `patchwork` / `ggdist` / `ggalluvial` / `ComplexHeatmap`）两条生产栈中均核实 1:1 真实物理尺寸、独立 `8 pt` Bold `A, B, C` 编号（无 `ABCD + 子图标题` 冗余头标）、常规 `6–7 pt` Regular Arial 嵌字且无 Type 3 回退、是否针对多维关系正确选用高阶视觉范式（并拦截三维柱饼等炫技失真）、单轴单一物理单位、真实密度截断以及零文字与图例碰撞。
   - **生物学机制示意图**：核实源码是否为可控制、语义分组良好的矢量 `<svg>`、视觉精细度是否贴合解释目标（信号布线采用简洁平涂轮廓；涉及细胞/组织形态时采用平滑三次贝塞尔轮廓与适当亚细胞景深）、描边是否采用协调深一阶同色系、通路箭头是否依证据分级（`→`、`⊣`、`⇢`）、图内文字是否保持 `1–4` 词 Regular 深墨色标注（无加粗彩标配浅灰副标题的堆叠和括号小字注释），且完全杜绝 AI 位图生成、简陋 `#000000` 描边卡通色块或塞满整句的流程图方框。
   - **局部有界微调**：核实仅目标标签或指定图元发生修改，其余面板几何结构、数据与样式均完整保留未动。
2. **保持评测公正独立。** 向全新测试执行者提供贴近真实场景的提示词与原始输入数据，不预先泄漏待查缺陷清单；基于实际渲染输出的 PDF/PNG 图像目视验收，而不仅依赖脚本退出码或人工合成评分。
