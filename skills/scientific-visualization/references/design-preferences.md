# 构图层级、文字标注与个人设计偏好

适用于新建图件、实质性重设计及图件审查。执行局部微调时保留原有版式，仅按目标修改适用对应条款；用户或目标期刊给出的显式规范优先于本页默认设定。

## 全图科学叙事与多子图构图架构

- **以双层分工组织整幅图件：单个子图完成具体观测或比较，整幅全图讲透一条完整科学结果故事。** 期刊正文的每一幅主图（如 `Figure 1`–`Figure 6`，高水平期刊常包含 `6–12` 个乃至十余个子图）对应正文一个 `Results` 小节的中心论断，职责是围绕整图陈述式图题构建一条自洽闭环的科学证据链。动手布局前，先明确整幅图的**四段式叙事弧线**（依具体研究目标灵活取舍）：
  1. **场景切入与模型界定层**（多置左上首图 `A` / `a`）：精简队列入排或动物干预时序、`CT / MRI` 与生理采样解剖定位，或全局发现图谱（如组织单细胞 `UMAP`、连续血流动力学全景波形），交代研究对象与观测窗口。
  2. **原位定性与主表型锚点层**：代表性组织学与免疫荧光切片（低倍概览配高倍 `ROI` 放大框）、三维应变/灌注断层场对照、典型心室 `P–V` 环或跨轨道整合热图，让核心生物学现象直观可见。
  3. **多维定量证实与混杂拆解层**：紧贴定性或全景图旁，依托独立生物学样本单元 `n` 展示完整分布（云雨图、配对轨迹、时程/剂量梯度曲线、亚组效应森林图或 `RCS` 非线性曲线），同时剥离竞争解释（例如将单细胞均表达上调同亚群扩增区分开来）。
  4. **机制扰动、功能回补或阶段收束层**（常置底部收尾行带）：通路阻断、基因敲除或物理挽救对照实验及器官功能转归验证，必要时配一枚克制的局部机制偶联缩略图，完成本图论点的因果收口并自然衔接下一幅主图。
- **厘清“拆分为多子图（`A–L`）”与“整合为单面板高阶复合图”的界限。**
  - **独立分图编号**：凡承担故事链中**不同逻辑递进环节**的证据单元（例如实验设计 `A` → 细胞亚群全景 `B` → 标志基因矩阵 `C` → 空间原位染色 `D` → 独立供体定量 `E` → 流体切应力时程响应 `F` → 药物阻断及挽救验证 `G–J`），拆分为独立编排的连续子图，便于正文按 `(Fig. 2a)` → `(Fig. 2b, c)` → `(Fig. 2d, e)` → `(Fig. 2f–j)` 逐环推进论证。
  - **收束进单一复合面板**：共享同一物理横轴或同一实体主键的伴随视图（如多导联同步血流动力学波形 `ECG / MAP / Flow`、限制性立方样条同轴耦合底部暴露分布、主热图锁齐顶部临床亚型带与右侧富集条、低倍切片嵌高倍放大窗）直接整合为一张高阶复合面板（参见 [高阶复合图谱与进阶包工作流](advanced-chart-archetypes.md)），防止同一个观测被拆碎成彼此割裂的小方框。
- **建立主次视觉锚点与非对称行带网格。** 含 `6–12+` 个子图的双栏整页图（物理宽度 `174–183 mm`，整高 `160–200 mm`）应当依各环节在故事中的权重分配版面：设 `1–2` 个**视觉重心主面板（Hero panels）**（占行宽 `45–65%` 或跨行竖向展开，承载主空间视野、核心机制模型、多轨主热图或全景波形），将其余定量统计、配对检验与亚组对照以紧凑的**卫星面板**环绕排布；仅在对等同级指标并列对比时局部使用等宽小网格。
- **用三级留白间距律组织十余个子图的模块化阅读动线。** 靠留白跨度的明确层级划分实验模块，省略生硬的灰色边框盒或长分割线：
  - **跨叙事模块间距（`5–8 mm`）**：自然分隔上下或左右推进的不同实验阶段与体系（例如人类单细胞发现模块 vs. 离体机械牵拉功能验证模块）；
  - **同模块兄弟子图间距（`2.5–4 mm`）**：将代表性原位图或典型波形（如 `D`）与紧邻定量统计（如 `E`）一眼绑定为“定性—定量”配对组；
  - **单面板内联轨道间距（`0.8–2 mm`）**：锁紧同一复合面板内部的主图与边际注释轨。
  - 编号总体遵循**横向叙事行带（Row-band）自上而下、带内自左向右**的流畅 `Z` 字动线；若某跨行主图右侧垂直叠放两枚配对定量子图，可顺应该局部块采用“左主图 → 右上 → 右下”顺序，防止读者视线在整页往返折返。
- **统一全图编码身份、合并共享图例并分流纯技术质控。** 十余个子图共守同一套分组/亚表型色彩与线型编码；同一行带或模块共用的分组图例在模块首图或共享边缘**集中声明一次**，同色兄弟定量子图省去重复图例框；同物理量兄弟子图统一纵轴刻度范围，避免重复轴标签。只要多状态分布、配对轨迹、剂量时程与阴性对照共同撑起正文主线论证，均保留在主图中；仅将不进入叙事主链的纯技术质控（如建库深度、全套流式设门、批次校正诊断图）转入补充图件，保持主图证据链凝练有力。

## 分图编号、头标与画布洁净度

- **先载入对应媒介尺寸预设再定字号。** 布置任何标签前，先按 [SKILL.md](../SKILL.md#媒介物理尺寸与字号预设) 调取期刊论文、幻灯片（Beamer/PPTX）或海报的对应预设参数。
- **论文拼图仅放置独立分图编号。** 多分图复合图统一使用 **`8 pt` Bold** 正体无衬线编号（临床/*Cell*/*Science* 类默认 `A, B, C`；投 *Nature* 系列使用小写 `a, b, c`），置于各分图框外左上角并严守共同的水平与垂直对齐轴线。单面板独立图件与常规学术汇报幻灯片均不加分图编号，仅在演讲中确需口头逐一指向分图时破例保留。
- **严禁在分图编号后拼接子图标题。** 禁止在数据图上方放置 `A  Arterial pressure`、`B  Infarct volume`、`C. Volcano plot` 或概括性的 `ax.set_title(...)`；精确的轴标题（`MAP (mmHg)`、`log2 fold change`）、紧凑图例与图注已经完整承担变量与结论说明职责。
- **机制图内保持单字重洁净排印。** 机制示意图中的文字维持 `1–4` 词精简尺度并统一采用 **Regular** 深墨色（`#111827`），避免“加粗大标题 + 浅色小字副标题”交替堆叠、五颜六色的粗体标签或图内括号解释小字。
- **规范使用条件与模态小标签。** 仅当一组兄弟子图共享相同坐标轴或成像框、需要快速区分实验状态时，方可在面板上方或角部设置简短 **Regular** 标签（字号匹配当前媒介预设，且与分图加粗字母分开摆放），如分组（`Sham`、`I/R`）、时点（`2 h`、`24 h`）、荧光通道/染色（`DAPI / ZO-1`、`H&E`）或基因符号（*`Pecam1`*、*`Cdh5`*）。
- **保持论文画布无防御性杂文。** 论文正稿图件内部不加总标题、副标题、工艺横幅（如 `STUDY FLOW CHART`、`TECHNICAL ROUTE`）或微小免责声明/页脚（如“患者获益仍需……”），除非用户专门要求。冗余免责话术应直接删除，既不缩小塞入画布角落，也不搬进图注。
- **Notion 交付中的图注归属。** 在 Notion 中新建或更新科研图件时，将图题与图注完整写入图片块的**原生图注字段**（同时保留来源链接与提及），不要在图片正下方再多写一段重复的正文图注。

## 生物学命名、语境边界与连接关系

- **采用直观可解读的生物医学名称。** 优先展示明确的生物医学术语（如 `Glomerular podocyte`、`High-dose Fasudil`、`Capillary endothelium`），避免把原始聚类编号（`Cluster_4`）、代码内部变量名（`var_02`）或“作者—年份”缩写直接暴露成图上主标签。仅在确实需要跨分图检索对应时，把稳定编号低调附于次要位置。
- **用自然分枝而不是乘号串表达实验设计。** 借助清晰的时间或分组分枝配合简短文字标示干预、洗脱窗口与暴露序列（例如 `60 min preconditioning` → `24 h recovery` → `Stretch challenge`），避免生硬的公式化标签拼接（`Precond / Sham × Window × Challenge`）。真实的数学表达式、物理量符号及统计学交互项（`Group × Time`）照常保留。
- **在视觉上恪守实验系统与模型边界。** 绝不把来自不同物种、不同细胞系、不同造模机制或互不兼容时间窗的发现强行串在同一条连续信号箭头上，以免误导读者以为整条通路已在同一体系内获证；必须在画面构图分隔与图注文字中共同守住体系边界。
- **线条与连接符号必须有明确实指。** 图中的每一枚箭头或对比括号均须对应真实的实验步骤、物理输运、信号传递或统计比较；连线走位整洁、线宽统一、节点周围留白均衡、零文字压线碰撞，杜绝装饰性折返或无意义的短促回环。
