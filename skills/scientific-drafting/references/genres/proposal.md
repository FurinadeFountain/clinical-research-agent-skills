# 研究计划与基金申请

用于起草、重构或实质修订开题报告、研究计划与基金申请书；栏目篇幅与体例依目标项目年度指南而定，导师讨论稿按当前讨论阶段组织。动笔前先读取项目《决策与淘汰账本》（`DECISIONS.md` 或 Notion 顶部决策区，若有），严格执行**按研发阶段分流载体、L1 → L2 拍板闸门与保护主线净度**：

- **早期构思与初稿探索期（L0/L1，未过廉价证伪与方向拍板前）**：单稿轻量推进（控制在 1 页级核心命题与判别逻辑），只打磨核心矛盾断口、假说机制、1–2 个决定性判别对照及廉价证伪快检依据，显式暂缓仪器标定、伪影扣除、先验方差试算、多面板终图与操作规程。若方向尚未拍板而任务要求直接细化完整设计书或 `SOP`，须先一句直陈提示沉没成本与未核硬约束，获确认后再展开。
- **立项申报、课程开题与答辩冲刺期**（尚无近期上台实操排期，核心矛盾是说服评审与答辩攻防）：溢出细节多属**认识论效度证明、二阶排除对照与统计防漏**。采用**“精简主标书 ＋ 汇报 `Backup` 备答库”纵向分层蒸馏**——主标书遵循“立项依据讲透科学主线，研究方案承载技术控制”，标定阈值、阶段退守与多重比较规则在文内仅于“潜在技术难点与备选方案”表或统计小节**单点落位**（必要的论断条件与独立图注信息按 [共用落位原则](../../../scientific-prose/SKILL.md#条件保留与细节落位) 就近保留）；深挖出的二阶效度边界在制作答辩幻灯片时转入 `Backup` 备答卡片（按评委质疑切口索引）。严守**精简主标书为唯一权威维护源**单向派生汇报稿；若过程留存过全量推演底本，立即冻结为只读归档，杜绝多版本并行手改导致参数漂移。
- **湿实验、大动物或临床研究启动期**（已过 L1 证伪与方向拍板且有明确排期，核心矛盾是现场零失误执行与故障止损）：溢出细节多属**管路搭建、体模标定、给药剂量、止损阈值、循环救援与标本分装等动作规程**。采用**“精简科学设计书（Why/What，供导师与同行审阅比较逻辑）＋ 独立操作《SOP》（How/When，按术前—术中—终末时间流组织供现场照单执行）”横向正交拆分**，保持单一事实落点，微调操作参数不牵动科学设计书；前期立项课题正式进入湿实验阶段时，可将原难点表/`Backup` 中的台架准入与质控条款抽离升级为独立《SOP》。

## 输入与归属界定

- 获取待解的具体异常现象或认识矛盾、关键代表作及其条件边界、已完成前期工作、可用公开数据范围、拟开展实验及平台条件，以及目标体例要求。
- 清晰划分已发表文献证据、申请人或团队已完成前期工作与拟开展实验；缺少预实验数据或平台参数时如实标明范围，依据现有事实推进论证。
- 按对核心假说的直接支撑度筛选前期基础：优先呈现直接验证体系稳定性、目标表型差异或关键参数可测性的定量结果，并附样本量与统计说明；与主假说弱相关的泛化生信或前期试算予以精简或退居附表。
- 自有预实验有限时，依托目标变量与疾病已有关联的文献实证锚点、生理/物理量级估算、公开数据集二次分析线索或同尺度成熟方法先例确立路线可通；正式申报稿在**研究方案首阶段**简明交代待标定工作窗即可，早期初稿不必提前堆砌标度律推导与方差试算，同时避免以“立项完成后再证明可行”替代前瞻论证。

## 论证任务

- **现象断口与单主线收束（问题统领方法，防纯方法学滑坡）**：从确凿的异常观察、临床床旁两难或现有解释失效的边界切入，锚定特定病程或病理环节，确立**唯一核心矛盾主线**，说明解决后改变哪一项医学或生物学判断。除用户明确面向医学物理、纯影像工程或算法期刊外，**题名、摘要首段、研究目标与关键科学问题必须落在病理生理规律或临床决策判别上**（如缺血再灌注过程微循环灌注障碍的形成规律、肿瘤基质硬化突破上皮静息稳态的转导机制），误差分解方程、非循环验证与混杂剥离设计一律作为“研究方案如何可靠回答该问题”的支撑手段，**严禁将“为某设备建立估算公式”或“如何将信号 X 从混杂 A/B/C 中分离出来”反客为主写成课题终极目的或关键科学问题**。避开空泛疾病负担套话，伴随或竞争情境优先降维为判别对照或适用边界检验。
- **场景与作用关系聚焦及范围真减法**：问题收窄聚焦具体病理生理场景以及物理或微环境条件改变细胞/器官功能的作用关系，当现象或载荷传递机制尚未确立时，暂不强行锁死单一信号分子。面对课程开题、探索性立项或有限周期课题，将主干严格收束在 **2–3 个紧耦合认识层级**内：若跨尺度链条（如“原位现象→新平台制造→流场反演→基因亚型细筛→在体治疗回救”）过长导致处处依赖未验证假设，优先做**实验范围真减法**（砍除高混杂跨尺度支线或下游亚型细筛），严禁维持过载全链条仅做文字压缩，亦不得在缺乏预实验依据时编造精确到个位数的质控合格门槛。跨学科变量写入核心假说时须作为有梯度的待检原因变量进入设计。
- **代表作认知边界切分与创新性自检**：围绕关键代表作交代其研究体系、实际操纵与比较条件、样本单位、推进的认识层级（新现象、新概念、新方法能力、新机制或临床效用）及尚待跨越的边界，使相邻工作合围出本课题的切入位置，摆脱按时间平铺文献。正面回答“若仅把现成方法搬入新病种即可解决，既往研究因何受阻”（如混杂因素未拆开、原位尺度不可见或主流假说存在盲区），以明确认知障碍替代“尚无报道”或简单技术拼接充当创新依据。
- **概念、干预与测量的因果及操作化映射**：在核心构念、实验主动施加的干预以及终点实测读出之间建立明确、可检验的因果与测量映射；涉及修复速率、恢复过程或持续力学记忆类命题时，配置基线、暴露即刻与撤除刺激恢复期的动态序列观测，以区分初始损伤轻重、不可逆破坏与真实恢复过程。跨尺度载荷标定、操控确认与替代指标效度边界统一收束在**研究方案/实验方法专节**简明交代，不打断立项依据的因果主线。
- **栏目职责分工、关键依赖识别与双图协同**：明确研究目标（拟获认识）、研究内容（待回答的子问题与范围）与实验方案（分组对照、干预控制、测量指标与统计判据），以及研究意义（领域认识或临床参数价值）与特色创新（视角切换或判别设计增量）之间的职责去重；预期结果采用“若观察到……则支持……；若呈现……则提示……”的条件判读语气。研究基础交代前期发现或技术储备对下一步研究的直接支撑；可围绕同一假说从互补切面推进，亦可组织依托前期锚点锁定优先候选的阶段性递进，均须识别关键串联依赖、写清进入下一阶段的条件，并为高不确定性环节预设双赢判别或保底备选方案，避免整份设计悬于单一未经证实的阳性预期结果。立项依据收束处配**科学假说机制示意图**（依托解剖或细胞空间构图承载因果链，以实线和虚线区分已证实通路与待检假说），研究方案总览处配与正文语种及符号一致的**总体技术路线流程图**（展示阶段递进、判别对照、主要终点与备选分叉）。

## 关键核查点

- **标题中心词、认知层级与转化承诺匹配**：核对结论落在现象建立、局部载荷传递、细胞感知转导还是在体病理后果哪一层级，保持标题中心词、总目标与拟完成实验处于同一层级。机制初建阶段将远期临床价值定位在阐明机理或识别潜在干预窗口，仅在具备明确临床队列差异或前期干预依据时，才将治疗优化或个体化生物标志物列为直接目标。
- **关键科学问题与技术质控难点隔离**：“拟解决的关键科学问题”仅提炼认识论层面的核心因果或机制断口（通常 1–3 条）；光学或力学标定、折射或运动伪影扣除、界面参数等效控制及敏感性验证归入研究方案或“潜在技术难点与备选方案”，保持正文骨干与主路线图聚焦决定核心假说成立与否的决定性比较。
- **关键依赖与单点失败风险控制**：核查平行内容或阶段性递进（如发现接验证）的前置支撑是否充分、进入下一阶段的判断条件是否明确，以及关键分叉节点未达预期时是否仍有可回答明确科学问题的备选方案。
- **特异性或依赖性主张与判别对照配对**：当标题、假说或目标主张某种效应具有细胞类型特异性、界面或微环境依赖性、时相依赖性或通路排他性时，方案中配置剥离或替换该条件的平行判别对照；当限定词仅用于界定研究对象或临床场景范围时，明确选型依据与外推边界即可，不必机械增设跨病种、跨谱系或全时空对照。
- **研究层级、样本独立性与分设计把握度校准（归入统计方案专节）**：在正式申报稿的统计分析小节明确独立实验单位（患者、动物、供体）与嵌套观察单位（解剖区域、腺管或肾单位、视野、细胞、时点、培养孔），不可逆损伤按平行或配对设计处理并匹配分层或混合效应模型。锁定唯一主要终点与多重检验控制；缺乏先验组内相关系数（`ICC`）时在统计小节一句写明暂定样本量依据与预实验方差校准，避免笼统宣称全部次要比较或高阶交互项均具备 80% 把握度，也不将这些统计技术限定塞入摘要、研究目标或立项依据。
- **生物学/临床功能终点与真实病态微环境校准**：核验核心读出是否匹配所宣称的生物学或临床结论层级（如可回收细胞或上清时，不单凭上游钙瞬变或单一转录本代表免疫功能激活），避免机制未明前过早锁死单一信号分子靶点；在体或离体模型须正视真实病态微环境中并存的主导细胞群体与干扰路径，必要时以无偏筛选替代单一路径预设。
- **规范学术文体、反生造词与防代码式防御长句**：摘要保持计划语气与清晰短句递进，剥离微球粒径、通道壁厚、给药剂量、统计校正细参等操作细节；定稿前清除内部路线标签（`模式 M0–M3`、`Step 2A`、`路线 A`）、**生造偏正复合名词及英文审阅直译黑话**（一律还原为学科通行术语或自然动宾短语，正反例见 [研究解释对照库](../../../scientific-prose/references/complete-research-explanations.md#问题诊断与修订准则)），拆解合入审阅意见时靠分号与长串定语硬拼成的百字代码式长句，把二阶边界留在难点表或口头讨论，确保科学主线自然易读。

## 完成标准

- 审阅者在短时初筛内即可串联“待解断口的重要性、引入核心变量或方法的必要性、拟定对照对竞争假说的判别力”三步主线。
- 标题、摘要、研究目标、研究方案与路线图之间的限定范围、变量名称与因果强度完全一致，已做工作与拟做计划清晰区分；需要整体叙事推进参考时查阅 [经核对的标书论证范例](../proposal-examples.md)。
