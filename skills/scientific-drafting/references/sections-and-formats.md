# 章节与载体

在所属体裁规范之上叠加本表要素；实际期刊、机构与课程明确要求优先。

| 写作单元 | 论证功能 | 核查与执行要点 |
| --- | --- | --- |
| 标题与小标题 | 点明核心问题、因果关系或比较维度 | 简短自然且匹配正文证据强度；按任务灵活选用陈述句、精准名词短语或规范栏目 |
| 摘要 | 在篇幅内凝练目标、依据/方法、核心发现与结论 | 原始研究默认采用结构式摘要；非结构式导语段按“1–2 句领域背景 → 核心未解断口 → 本文核心发现与关键定量证据 → 对领域判断的具体推进”组织。基金申请书与研究计划采用计划语气（常为紧凑单段或两段式），按“临床或科学问题与既有缺口 → 核心假说 → 递进研究内容与关键判别对照 → 预期认识或转化意义”组织，剥离试剂剂量、微球粒径或器件尺寸等 SOP 细节；正文调整时同步关键数值与适用边界 |
| 开篇研究语境框（按期刊体例） | 浓缩领域既有边界、本研究增量与综合启示 | 如遇 `Research in Context`、`Key Points` 或 `Take-Home Message` 栏目，分别凝练“既往证据与方法局限 → 本研究新增的决定性认识 → 综合后的临床或机制启示”，与摘要和讨论核心结论严密对齐 |
| 引言 / 立项依据 | 建立观察异常、既有解释不足与研究问题由来 | 按“领域已确立共识 → 子领域相持分歧或解释受阻边界 → 本文直接切入的决定性未知”逐层收束，先交代依赖前提再引出核心假说；命题议论文（Tutorial Essay）与观点评论须在引言末句正面给出统领全题各子问的中心论断；每一处背景陈述直接服务于引出问题 |
| 方法 / 研究方案 | 交代足以判读或复现的设计、对象、比较与分析 | 原研如实写已做操作，方案清晰写拟做对照；如实保留信息缺项 |
| 结果 | 报告实测对象、对照比较、方向与不确定度 | 首段可用 2–3 句简明交代总体实验切入设计与观测逻辑以锚定全局；随后与方法设置及图表数值严密对齐，将客观测量发现同机制解释分开表述 |
| 讨论 / 综合 | 阐明认识增量、研究分歧根源、替代解释与成立条件 | 从主要发现推进论证而非复述结果，机制推测维持恰当归属；命题议论文在各主节末尾保留 1–2 句扣回中心论点的阶段小结（不被综述/标书“去总结”规则误删） |
| 图表与独立图注 | 承担核心比较关系并支持脱离正文独立判读 | 写明研究对象、组别、分母、单位、时点及关键条件；正文直接阐明图表支撑的比较结论 |
| 术语表 / 缩略语表 | 解释非常见核心术语、变量与复合指标 | 沿用本稿受众收录范围与既有排除项，新增或整理时参照 [术语所指与缩略语表规范](../../scientific-prose/references/complete-research-explanations.md#术语所指与缩略语表规范) |
| 补充材料交叉引用 | 确保正文中具体提及准确落位至补图、方法或推导 | 重排后逐一校验编号、标题与内容一致；本地文稿可运行 [链接检查脚本](../scripts/check_internal_links.py)，原生页面直接回读核实目标区块 |
| 讲稿 / 幻灯片 | 按听众认知顺序讲述问题推进与图中关键比较 | 讲稿解释图意与页间逻辑衔接；实际幻灯片制作与改版切换至 [幻灯片制作与交付](../../presentation-workflow/SKILL.md) |
| 审稿回复 | 逐条回应评审关切、呈现自包含修订证据并与主稿保持一致 | 开篇先设简短全局核心修订导览；将复合审稿意见拆分为独立子编号逐问作答，每条首句直接给出明确结论（已采纳修改、已补充分析或凭据维持原判）；直接在回复条下内联贴出改后关键正文句段、新增图表与精确页行位置，并用清晰三层版式区分审稿原文、作者回应与入稿修订文字，确保承诺与权威主稿严格一致 |
| 翻译 / 双语改写 | 跨语种忠实再现科学论断与边界 | 重组语序保证目标语自然可读，严格锁定原有对比条件、方向、数值、归属与不确定度 |

处理分子命名时先辨清基因、RNA、蛋白或统计符号所指再应用斜体与大小写规范。除非项目或目标期刊另有要求，默认采用温哥华（Vancouver）顺序编码引文格式；Zotero 操作保留稳定条目键与独立授权范围。唯一权威真值源维护、Notion 操作、原生 HTML 副本与 TeX/PDF 输出规范遵循 [唯一主稿与交付](../../scientific-prose/references/notion-tex-workflow.md)。
