# 协作与改动传播

由一位主笔统筹唯一权威主稿。根据任务实际的独立注意力负担配置最小协作成员，所有协作者针对同一固定候选快照开展工作。

## 组织模式选择

| 稿件任务特征 | 最小实用配置 |
| --- | --- |
| 局部段落或单一紧密主线 | 主笔通读完成；确有必要时配一位编辑兼顾结构与读者理解 |
| 全文重构论证且研究对象、模型或比较核对工作量大 | 主笔统筹论证、行文与读者理解；加派一位研究比较编辑同稿并行核对结果范围与一手依据 |
| 全局结构与局部表述分属各自明显瓶颈 | 先由一位编辑兼看，负担明确不可兼顾时再拆分为全局与读者两位只读编辑并行 |
| 若干相对独立的研究章节 | 按独立论证单元切分并行，附必要邻接上下文，由主笔统一维护共享定义与跨章衔接 |
| 共用同一假说或模型的强耦合文稿 | 主笔先行锁定共享前提，各视角基于同一文本审校，统一回传意见 |

已核条件不变的局部措辞修改由主笔直接完成。资料来源整理可先于写作并行开展，但正文结论须待关键依据澄清后再行落笔。

## 角色边界与一次交接

- **主笔**：确定体裁、结构与证据落位，执行变化触发检查，整合全部审阅意见并作为唯一写入者更新主稿、同步交付输出。
- **全局编辑**：核查各节论证增量、证据层级、共享前提以及摘要和结论之间的相容性。
- **读者编辑**：核查陌生术语首现位置、实体指代、比较参照、认知顺序及概念归属清晰度。
- **研究比较编辑**：以单个研究结果为粒度核对原稿、新稿与一手依据中的人群/模型、对比条件及推论边界（可由主笔或既有编辑兼任）。
- **科学审阅**：按 `academic-reviewer` 在成稿交付节点执行一次独立学术审计。

交办协作者时直接提供固定候选快照、体裁与阶段定位、核心科学问题、适用用户更正、原新对照配对及已有原始文献位置，直接复用既有配对与已读来源。所有编辑严格保持只读，首轮独立阅稿，仅回报影响主线推进、读者理解或事实范围的有据实质问题（位置、依据与影响、最小减法改法及依赖范围），不索要预防性技术免责补丁；无问题时简明声明已核范围即可。各编辑子代理显式继承父会话模型（`Model="inherit"` 或 `swarm` 默认继承，`academic-reviewer` 遵守其专属合规路由）。

## 短准备与原新对照

适用于带批注修订、重要限定修改或经历多轮返工的文稿；轻量小改直接在上下文完成：

1. **提取适用更正与共享前提**：主笔通读原稿及讨论记录，整理本次生效的用户更正、关键定义及出处；修订完成后在变化说明中给出核心要求在新稿中的实际承载位置。保留准确清晰的原有研究陈述，仅修需变动环节。
2. **以结果为单元实施三端对照**：对照原稿与新稿配对论断，对核心定量发现、复合人群或联合终点直接回到一手正文、方法或图注，核查样本人群/亚组、模型、干预对照、时点、指标及结论范围，并使每个限定绑定至对应结果；删去研究引用时同步清理正文残留综合、图表与编号。
3. **追踪锚点与脚本辅助**：复合陈述或关键分母变动保留简短“来源对象/条件 → 结果 → 新句位置”映射备查。本地 Markdown 文稿可运行 [研究段落配对脚本](../scripts/compare_cited_passages.py)（配合 `--source-manifest` 与 `--source-index` 定位已存 XML 章节或图注）或 [落点检查脚本](../scripts/check_revision_coverage.py) 辅助定位，核查结论仍须负责人员实际读段确认。

## 合并修改与双向依赖回查

主笔整合意见时，先裁定共享事实、概念定义与前提条件，再统筹局部文字；严控正文信息负载，以删紧越界表述和向方法/方案专节下沉细节代替向主线塞入防御性补丁，并对删改建议合并判断，防止两处互为依托的前提条件一并被删空。

| 变更性质 | 主笔需复核的关联范围 | 定向回交原编辑的条件 |
| --- | --- | --- |
| 陌生术语首现迁移或删改 | 名称与实体身份、前文铺垫、后文复现、独立图注及参照坐标 | 调整后概念清晰度或指代仍有争议时回交读者编辑 |
| 删并、压缩或大幅重排 | 原有比较条件、模型假设、不确定度说明与图表用途是否完整保留 | 科学含义变更转交科学核查；核心解释断层回交对应编辑 |
| 核心主张、数字、主要基线或适用对象边界修改 | 一手依据、前文铺垫、后文推论、摘要、结论及对应表图数值全域对齐 | 核心实验控制或因果模型实质重构时可做至多 1 轮局部复核；影响读者前提时回交编辑 |
| 操作标定阈值、几何/光学误差边界、退守判据或多重检验规则增补 | 按 [共用落位原则](../../scientific-prose/SKILL.md#条件保留与细节落位) 集中技术细节，保留独立判读所需条件 | 主笔核验单点落位准确即收尾，不触发复核 |
| 补图、方法或推导跳转变更 | 所有正文提及、链接及目标章节/图件内容对齐 | 仅修复链接或名称而科学含义不变时，主笔核验后即可收尾 |
| 摘要、图注与双语/派生版本 | 反查唯一权威源稿中的限定条件、方向、归属与结论强度 | 语义改变按前序规则复核；单纯同步未变论断复用既有审阅 |

明确而局部的文字修复由主笔通读邻文直接闭环；仅当存在未决分歧、核心前提变动或修复引入新漏洞时，再将变动片段发回相关原编辑复核，随即停止并交代实际核验范围与待查缺口。
