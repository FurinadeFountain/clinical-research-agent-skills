# 科研行文与润色

先读当前原稿、必要邻文与适用用户更正；保留人工手改、真实比较和论断强度，直接交付修改后成文。局部改句不自动扩成全文重写或独立审阅；用户指出系统性表达问题、要求全文润色时，再检查作用域内同类段落。

## 表达与解释

- **发现明确**：交代研究对象、暴露或干预、实际对照、观察时点、实测指标与变化方向，点明关键对照或时序设计所排除的替代解释。以条件性规律组织文献，避免按作者堆 Results；评价性用词须落在具体结局上，不用“记录了、评价了”替代实际发现，禁用 `"killing"`、`"response"`、`"activation"` 等伞状词混同不同实验体系的实测终点（如脱颗粒、细胞裂解、细胞因子分泌与单细胞成像读数）。复合指标保留各组分方向并说明合并理由；不凭较小分母推测失访、排除或死亡原因。
- **论证连贯**：每节回答一个独立问题，一段围绕一个连贯论点组织；命题议论文与观点评论按体裁保留引言中心论断及各主节末尾扣题小结。陌生对象、术语及比较参照在需要的位置解释；先建立前提，再推进机制或尺度关系。句首承接已知信息，句末给出新信息；“仍、因此、然而”必须有真实逻辑支撑。不因更换作者机械分段，也不留无过渡碎段。
- **语义准确**：区分已发表结果、已完成工作、假说、预测、目标与拟开展计划。保持关联、因果、阴性发现与等效性各自的证据强度；不得为衔接流畅补造实验或结果。术语、基因/蛋白层级、单位和同一实体称谓保持一致，中文专业名词优先采用 CNCTM 规范译名；**严禁为压缩字数或直译英文审阅意见而生造偏正复合名词或认识论黑话**，一律改用本学科通行概念或自然主谓/动宾短语（正反改写案例见 [研究解释对照库](references/complete-research-explanations.md#问题诊断与修订准则)）。
- **语体自然**：采用具体生物学主体、临床事实和直接动宾。去掉制稿旁白、空转预告、无依据的翻案句与叠加谦抑词；“评价、描述、检验、判别、读出”等按具体语境使用，不设词汇黑名单。保留有判别价值的否定对照、真实时序、平行比较和必要过渡，不机械清零连接词、排比、问句或括号，不刻意制造句长波动。**中文控制单句信息载荷**，合入审阅限定时优先删紧修饰或另起短句/归入难点表，严禁靠分号、长串前置定语与多重括号把前提、公式、操作和免责条件焊成百余字的“程序代码式长句”；**英文善用让步、对比与分词从句**（`Although...`、`Whereas...`、`thereby...`）将适用边界自然嵌入主干复合句，严禁拆成连续电报式单句或在段尾堆叠孤立免责短句。
- **标题与引用**：论述性小标题优先用证据支持的简短判断，也保留恰当的名词性、方法学及规范栏目标题；避免中圆点、斜杠或竖线串接关键词。除项目或期刊另有规定，采用 Vancouver 首引顺序编码。删改文献陈述后同步核对文内引用和文献表。

文献综合、解释缺环或全文润色时，按问题读取 [研究解释对照库](references/complete-research-explanations.md#问题诊断与修订准则) 与 [自然行文专项检查](references/complete-research-explanations.md#证据范围与自然行文专项检查)，不在单句小修时加载全部案例。用户请求科研 Write Like Me 时直接应用本规范；仅在需要新样文或切换文风时检索，实际读过才声称依据样文校准。

## 条件保留与细节落位

本节统一维护科研写作、编辑和学术审阅共用的落位原则：

- 核心比较、测量参照、结论强度和外推边界所必需的条件融入对应论断；供独立阅读的摘要、表格和图注保留各自必要的分组、分母、单位及限定。不得以“单点落位”删去这些条件。
- 操作标定、伪影扣除、统计校正参数、误差控制与备选步骤在所属方法/统计专节集中说明，不反复刷入引言、目标或图注。技术细节影响当前结论成立时，就近给出必要概括，详细规则仍由原专节维护。
- 构思和初稿聚焦问题、假说与决定性比较；正式稿补齐适用方法。阶段性 `Backup` / `SOP` 拆分按 [申请书体裁](../scientific-drafting/references/genres/proposal.md) 执行，不在普通润色中另建文件。
- 删除重复前提时，对叠加改动后的关联上下文统一核查，确保至少在读者需要的位置保留完整解释；涉及互相补位的删减，参照 [依赖范围校验](../scientific-editorial-review/SKILL.md#整合修改且不丢失解释)。核心主张、方向或基线变化时同步对应摘要、正文与表图；语义未变的局部修改不扩大检查。

## 任务交接与保存

从零起草、体裁选择或结构重构由 [scientific-drafting](../scientific-drafting/SKILL.md) 统筹；普通修辞与图注修改在本技能内完成。仅当用户要求完稿指标诊断及前后复测时使用 `lieflat-less-ai-tone`（如本地已安装该可选指标诊断技能），不叠加到日常润色。

聊天讨论与直接贴入的草稿默认在聊天交付。要求保存、维护既有页面或新建长期迭代正式文档时，按 [主稿与交付](references/notion-tex-workflow.md) 操作：改前读、保留手改、仅在结构大改/批量替换/表行替换后局部回读并附链接（局部单段更新接口返回成功即直接交付链接，不整页重拉）。已有 Markdown/TeX 项目不自动迁移；只在任务需要时输出 TeX/PDF，不另加定稿确认。

## 交付核验

通读改动与依赖范围，核对数字、归属、比较条件、引文及图文对应。完稿清除内部路线/模式/多代理阶段标签、旧稿分路代号、裸转写行号和修稿旁白；假说保留归属与条件，实验方案用具体干预名称和有依据的前提，不以符号串代替分组时序。

本地完整稿或准备写入正式 Notion 页面的长稿运行 [lint_manuscript.py](../scientific-drafting/scripts/lint_manuscript.py)；仅检查节选或未附文末编号文献表的 Notion 构思/方案页时传 `--fragment`。该脚本检查标题、内部标签、括号重复、Markdown 数字引文、中文代码式防御超长句及英文电报式短句顿挫；TeX 引文编号与文献表需核查项目编译输出，脚本会标为未核。它不能证明科学正确或行文优良，不为消除提示而损失内容。必要时使用 [PDF 字体检查](scripts/check_pdf_fonts.py) 或 [批注提取](scripts/extract_pdf_annotations.py)；排版变动后目视检查受影响页面。科研图件本身的制作/修改由 `scientific-visualization` 承接。
